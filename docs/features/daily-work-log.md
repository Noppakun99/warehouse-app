## แหล่งข้อมูล (ดึงอัตโนมัติ)
| งาน | แหล่ง | วันที่ที่ใช้ |
|---|---|---|
| ลงใบเบิก | `รวมเบิกยา\_ทะเบียนใบเบิก.csv` (สถานะ ใช้) | วันที่ลง |
| รับยาเข้าคลัง (ซื้อ/สนับสนุน/ยืม/คืน/แลก) | ชีท `รับยา` | วันที่รับ (O) |
| ยืม-คืนยา | ชีท `รพ.ยืมยา` | N วันที่ให้ยืม · P วันที่รับคืน |
| ส่งบิลให้จัดซื้อ | `_ทะเบียนส่งบิลจัดซื้อ.csv` | วันที่ส่ง |
| เอกสารสรุปตรวจรับ | `_ทะเบียนเอกสารตรวจรับ.csv` (ข้ามใบยกเลิก) | วันที่ออก |
| ข้อสังเกต (→ ช่องหัวหน้า) | `_ข้อสังเกตบิลและใบเบิก.csv` | วันที่ตรวจ |

**เรื่องที่ไม่มีทะเบียน** (ตัดสินใจ · เปลี่ยนวิธีทำงาน · รอใคร · หลักฐานที่ได้รับ) → เขียนเองใน `บันทึกการทำงาน\_บันทึกเพิ่ม.csv` (`วันที่,หัวข้อ,รายละเอียด,แจ้งหัวหน้า`) · `แจ้งหัวหน้า = ใช่` → ขึ้นช่องหัวหน้า ไม่ใส่ → ขึ้นช่องงานที่ทำ

- การเซ็นรับ (ผู้ตรวจรับ/จัดซื้อ) — วันที่ในทะเบียนเป็นวันที่ผู้เซ็นเขียน ไม่ใช่วันที่คลังได้รูปคืน
- การพิมพ์เอกสาร (`_สถานะพิมพ์.csv` วันที่ยืนยันพิมพ์) · นำเข้าแอป · ใบแจ้งย้ายที่เก็บ
