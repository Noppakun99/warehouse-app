## เกณฑ์ (user เลือก 18/11/2569)

- นับ **เดือนเต็มติดต่อกันที่ไม่มีเบิกใช้จริง** ย้อนจากเดือนที่แล้ว (เดือนปัจจุบันยังไม่ครบ ไม่นับ — แต่ถ้าเดือนนี้มีเบิกแล้ว = เคลื่อนไหว ตัดออกทันที)
- ≥ `REPORT_MONTHS` (6) = แจ้งหัวหน้า · `WATCH_MONTHS` (3)–5 = เฝ้าดู
- จุดเริ่มนับ = เดือนเบิกใช้ล่าสุด หรือเดือนรับเข้าครั้งแรก (อันที่ใหม่กว่า) — ยาเพิ่งเข้าต้องมีเวลาถูกเบิกก่อน · ไม่เคยเบิกเลยและไม่มีวันรับ = นับจาก `historyStart` (เดือนแรกที่มีข้อมูลเบิก)
- **ไม่นับเป็นการใช้** (`isRealUsage`): `NON_USAGE_DEPARTMENTS` 4 ค่า (เบิกเพิ่มจากความผิดพลาด · เบิกยาหมดอายุจากคลัง · เบิกเพื่อแลกเปลี่ยนคืนยา · คืนยา) + หน่วยงานนอก รพ. (`รพ.…` · `บริษัท…` · องค์การเภสัชกรรม · `สถาบัน…`) — ชื่อต้อง query DB ยืนยันก่อนเพิ่ม (Rule #16)
- รวมระดับยา (`drugKey` = รหัส หรือชื่อถ้ารหัส `-`) · มูลค่า = Σ qty × ราคา/หน่วย ราย lot

## ผลต่อแถว

- `suggestion`: มี lot คืนบริษัทได้ (นโยบาย `ok`/`due` และไม่ใช่ยาสนับสนุน) → "คืนบริษัท n/N lot ภายใน <วันที่>" · ยาสนับสนุน/บริจาคทั้งหมด → โอน/เร่งใช้ · อื่นๆ → เร่งใช้/โอน รพ.ข้างเคียง · ยาที่ต้องมีในคลัง (`essentialGroup`) ขึ้นต้น "ยาต้องมีในคลัง — เฝ้าวันหมดอายุ"
- `ptc`: ตัดออกแล้ว (Master A มี "ตัดออก") · ไม่เสนอ — <กลุ่ม> (ไม่ใช่ยา · สมุนไพร · ยาเสพติด · สารละลาย · ยาโรคติดต่อตามนโยบาย · ยาต้านเชื้อฉีด · VEN Critical) · `report` ที่เหลือ = "เสนอพิจารณาออกได้"
- `usedBy`: หน่วยงานที่เคยเบิกใช้ (เบิกล่าสุดก่อน แล้วเบิกบ่อยก่อน) — ให้หัวหน้าเห็นว่าใครใช้ก่อนตัดสินใจ
- เรียง: ไม่เคลื่อนไหวนานสุดก่อน แล้วมูลค่าสูงก่อน

## หน้าแอป

- เมนู รายงาน → "ยาไม่เคลื่อนไหว" · role staff/admin · grant รายคนได้ (`GRANTABLE_SYSTEMS` key `dead-stock` — Rule #23)
- `fetchDeadStockData()` ([db.js](../../src/lib/db.js)) โหลด 5 ชุดพร้อมกัน: inventory (มี `price`) · receive_logs (`fetchPolicyReceiveRows` — ใช้ทั้งนโยบายคืนราย lot และวันรับครั้งแรก) · `fetchSwapPolicies` · dispense_logs `qty_out > 0` (ผ่าน `_pagedParallel` — ยิงหลายหน้าขนาน เพราะเบิกเป็นหมื่นแถว) · `drug_reorder_config.risk_group` (VEN)
- แปลงเป็น input ด้วย `stockLotsFromInventory(rows, parseExpDate)` + `firstReceiveMap` (pure ใน deadStock.js)
- **บริษัท**: `inventory` ไม่เก็บบริษัท (`supplier` เป็น `-` ทุกแถว) → ใช้ `company` จากนโยบายคืนบริษัทราย lot แทน — อย่าแก้ไปอ่าน inventory
- แท็บ ไม่มีเบิก ≥6 เดือน / เฝ้าดู 3–5 เดือน / ทั้งหมด + ช่องค้นหา · การ์ดสรุปจำนวน/มูลค่า/เสนอ PTC ใช้ array เดียวกับรายการ (Rule #6) · กางแถว = ราย lot + หน่วยงานที่เคยเบิก + ปุ่มเปิดบัตรยา · วันที่ใน `suggestion` (ISO) แปลงเป็น พ.ศ. ตอนแสดง
- อ่านอย่างเดียว — ไม่มี mutation จึงไม่มี audit log
- E2E: [tests/18-dead-stock.spec.js](../../tests/18-dead-stock.spec.js) (อ่านอย่างเดียว 2 เทส — ไม่ fix จำนวน ตรวจว่าการ์ด = แท็บ = แถว)

## ราคาใน inventory

`inventory.price` (numeric) มาจากคอลัมน์ "ราคา/หน่วย" ของชีท Master (`parseMasterGrid` ใน masterSheet.js) · นำเข้าผ่าน `import:master` หรือปุ่มนำเข้าจาก Excel (`INVENTORY_SPEC` มีช่อง "ราคา/หน่วย" — ส่วนต่างราคาจะขึ้นในด่านตรวจ) · NULL = ไม่รู้ราคา → มูลค่า lot นั้นเป็น 0
