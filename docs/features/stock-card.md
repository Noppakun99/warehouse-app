## ปัญหาของหน้าเดิม (จากรูป Acetaminophen 500mg — 16 lot 103 แถว)

ตาราง 11 คอลัมน์ล้นขวา (Exp โดนตัด) · ทุก lot ปนในตารางเดียว คงเหลือ lot อ่านแล้วกระโดด · หัวการ์ดแน่น (ป้าย 4–5 + ย่อหน้าเตือนยาว) · ป้ายกดได้กับกดไม่ได้หน้าตาเหมือนกัน · ศัพท์เทคนิคโผล่ (`unpivot`, "ยอดที่บันทึกไว้") · แถวเบิกโชว์ป้าย `ยกยอด`

## สมมติฐานที่ยังไม่ได้ถาม user (บอกในแผนแล้ว — ผิดให้แก้)

- ลำดับในรายการ lot: มีป้ายเตือนจริง (ยอดไม่ตรง/กรอกผิด/ติดลบ) ขึ้นก่อน → lot ที่ยังมีของ เรียงหมดอายุเร็วก่อน → lot ที่หมดแล้ว (คงเหลือ 0) ท้ายสุดสีจาง
- ตัวกรอง "ชนิดรายการ" ถอดออก (ไม่มีป้าย `ซื้อยา`/`ยกยอด` ให้กรองแล้ว) เหลือตัวกรองช่วงวันที่
- แผง "ตรวจหายาที่ยอดไม่ตรง" และ "ของรอคืนจากบริษัท" ไม่แตะ
