# การ์ดคลัง lot (Stockcard) — ออกแบบหน้าจอใหม่

**สถานะ: ตัดสินใจครบแล้ว 13/11/2569 (grill 7 ข้อ) · user ยืนยันสมมติฐาน 3 ข้อ 14/11/2569 · ขั้น 1 เสร็จ 14/11/2569 (`stockCard.js` + test 141 ผ่าน) · ขั้น 2 (จอคอม) เสร็จ 14/11/2569 รอ user ดูภาพ 1280px — ขั้น 3–6 (มือถือ/ใบพิมพ์/E2E/เอกสาร) ยังไม่ได้ทำ** · ขั้น 2 เพิ่ม: บรรทัด "ยอดกลับมาตรงกัน" สำหรับจุดที่ผลต่างกลับเป็น 0 (เดิมขึ้น "ก่อนเบิก 44 ไล่ได้ 44 — ขาดไป 12" ชวนงง) · หมายเหตุตัด 2 บรรทัด (`line-clamp-2`) แทน `truncate` เพราะตาราง auto layout กว้างตามหมายเหตุยาวสุดแล้วล้นขวา · DriftModal: แถวกรอกผิดอย่างเดียวไม่โชว์กล่องเทียบผลต่าง (ผลต่าง 0 ชวนเข้าใจผิด) + สมการแถวไม่หักยอดใช้ หลัง = ก่อน · ขั้น 1 แก้นอกแผน 1 จุด: แถวไม่หักยอด (`บันทึกเท่านั้น`/`แก้ไขระบบ`) ตรวจ "แถวกรอกผิด" ด้วย หลังเบิก = ก่อนเบิก (เดิมใช้ ก่อน − เบิก = หลัง → แถว `บันทึกเท่านั้น` 152/154 แถวจริงขึ้นกรอกผิดปลอม) · นิยามคำอยู่ [CONTEXT.md §การ์ดคลัง lot](../../CONTEXT.md)

ไฟล์: `src/StockCardApp.jsx` · logic `src/lib/stockCard.js` (`npm run test:stockcard`) · E2E `tests/13-stockcard.spec.js`

## ปัญหาของหน้าเดิม (จากรูป Acetaminophen 500mg — 16 lot 103 แถว)

ตาราง 11 คอลัมน์ล้นขวา (Exp โดนตัด) · ทุก lot ปนในตารางเดียว คงเหลือ lot อ่านแล้วกระโดด · หัวการ์ดแน่น (ป้าย 4–5 + ย่อหน้าเตือนยาว) · ป้ายกดได้กับกดไม่ได้หน้าตาเหมือนกัน · ศัพท์เทคนิคโผล่ (`unpivot`, "ยอดที่บันทึกไว้") · แถวเบิกโชว์ป้าย `ยกยอด`

## สมมติฐานที่ยังไม่ได้ถาม user (บอกในแผนแล้ว — ผิดให้แก้)

- ลำดับในรายการ lot: มีป้ายเตือนจริง (ยอดไม่ตรง/กรอกผิด/ติดลบ) ขึ้นก่อน → lot ที่ยังมีของ เรียงหมดอายุเร็วก่อน → lot ที่หมดแล้ว (คงเหลือ 0) ท้ายสุดสีจาง
- ตัวกรอง "ชนิดรายการ" ถอดออก (ไม่มีป้าย `ซื้อยา`/`ยกยอด` ให้กรองแล้ว) เหลือตัวกรองช่วงวันที่
- แผง "ตรวจหายาที่ยอดไม่ตรง" และ "ของรอคืนจากบริษัท" ไม่แตะ
