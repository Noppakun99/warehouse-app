**Navigation shell (`AppShell.jsx` + `navConfig.js`):**
- `AppShell.jsx` — sidebar ถาวร (desktop `lg:pl-60` fixed / ยุบเหลือ `lg:pl-16` จำสถานะใน localStorage `sidebar_collapsed`; mobile = drawer + hamburger) ครอบ content ทุกหน้า. **แถบยุบแล้ว submenu กางเป็น flyout ลอยขวา** (`position: fixed` ไม่ใช่ absolute — `nav` เป็น `overflow-y-auto` จะ clip แผงที่ยื่นออกนอกแถบ). **โลโก้บน top bar = กลับหน้าหลัก** (`go('dashboard')` ตัวเดียวกับปุ่ม "หน้าหลัก" ใน sidebar — เดิมเป็นปุ่ม refresh ย้ายออก 2026-08-01); **refresh อยู่ที่ปุ่ม "โหลดหน้านี้ใหม่" ใน footer sidebar** + ปุ่ม ⟳ ใน title bar ของแต่ละ sub-app. มีปุ่ม refresh (เรียก `refreshPage`/subKey remount) + logout ที่ footer — sub-app **ไม่มีปุ่ม logout เอง** (sidebar คุม navigation). **ปุ่มย้อนกลับ (browser-like) = component กลาง `BackButton.jsx`** วาง **inline ซ้ายไอคอน/ชื่อระบบใน header ของแต่ละ sub-app** (เดิมเป็นปุ่ม floating ใน AppShell ที่ทับชื่อระบบ — ย้ายมา inline 2026-06-29 ให้สม่ำเสมอ ไม่ทับ). AppRoot ส่ง `onGoBack={goBack}` + `canGoBack` เป็น prop ให้ทุก sub-app; `BackButton` แสดงเมื่อ `canGoBack` เท่านั้น. **เพิ่ม sub-app ใหม่ต้องวาง `<BackButton onGoBack={onGoBack} canGoBack={canGoBack} />` ใน header เอง** (AppShell ไม่ render ปุ่มนี้แล้ว). **ยกเว้น `RequisitionApp`** ที่มีปุ่ม back ของตัวเองอยู่แล้ว (wizard-internal nav ผ่าน `PageHeader` `onBack`) — ไม่ใส่ BackButton ซ้ำ
- **แถบปุ่มล่างจอ (จอ < lg — Dashboard Phase 3, 11/10/2569)** ใน `AppShell.jsx` (`BOTTOM_NAV`): ผู้เบิก = หน้าหลัก · คืนยา · ประวัติเบิก (`dispense-mine`) · เมนู / staff+admin = หน้าหลัก · ตรวจนับ · แผนผังคลัง · เมนู ("เมนู" = drawer เดิม). `fixed bottom-0 z-30 h-16` + content `pb-16 lg:pb-0` — z-30 อยู่ใต้ drawer (40/50) และโมดอลทุกตัว (≥ 50). ⚠️ **padding ไม่ช่วย element ที่ sticky/fixed ล่างจอ** → (1) หน้าที่มีแถบล่างของตัวเอง **ไม่แสดงแถบ** (`NO_BOTTOM_NAV` = `requisition` — ส่งใบเบิก/อนุมัติ/ตะกร้า `fixed bottom-0` 7 จุด) (2) แถบ sticky ล่างของหน้าที่มีแถบ ต้อง `bottom-16 lg:bottom-0` (ReturnApp ปุ่มบันทึกการคืนยา) (3) Toast/ReqToast ยกเป็น `bottom-20 lg:bottom-*`. **เพิ่มแถบ sticky/fixed ล่างจอในหน้าใหม่ต้องเลือกข้อ 1 หรือ 2** (ตรวจด้วย [tests/15](tests/15-mobile-bottom-nav.spec.js) ที่จอเตี้ย 560 — จอสูงฟอร์มสั้นกว่าจอ sticky ไม่ติดขอบ เทสผ่านแม้ปุ่มจม)
- `navConfig.js` — `NAV_GROUPS` (เมนูจัดกลุ่มตาม workflow), `COLOR` (สีประจำระบบ — **เขียน class เต็ม ห้าม `bg-${c}-50`** Tailwind purge ตัด), `roles` filter ต่อเมนู (ตรงกับ `SYSTEMS.roles`). **เมนูแสดงเมื่อ `roles.includes(role)` OR `permissions.includes(item.page)`** — `AppShell` มี helper `canSee()` ([AppShell.jsx](src/AppShell.jsx)) ให้ admin grant สิทธิ์ระบบรายคนเพิ่มเหนือ role ได้ (ดู Critical Rule #23). shared กับ `DashboardV2Preview.jsx` (prototype เปิดด้วย `?v2`). **item มี 3 แบบ**: (1) leaf `{ page, ... }` → `onNavigate(page)` เปิดหน้า, (2) submenu `{ key, children }` → กางได้, (3) **action** `{ action, ... }` → `onFormAction(action)` ทำ action โดย**ไม่เข้า navStack/ไม่เปิดหน้า** (เช่น print) — dispatch ที่ `runFormAction` ใน [AppRoot.jsx](src/AppRoot.jsx); `NAV_ITEMS` filter action ออก (ไม่มี `page`). เมนู "แบบฟอร์มต่างๆ" ใช้ pattern นี้
