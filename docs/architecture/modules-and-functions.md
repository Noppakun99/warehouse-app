## Key shared functions

- **การ์ดตัวเลข Dashboard (`OverviewPanel`)** — 4 ใบ: รายการยาในคลัง · ใกล้หมดอายุ (lot) · **รอตรวจรับ (lot — แทน "ต่ำกว่า Safety Stock" 14/11/2569 เปิด `PendingReceiveModal` ใน [PendingLotCard.jsx](../../src/PendingLotCard.jsx) ด้วย `alerts.pendingReceive` ชุดเดียวกับตัวเลข)** · แจ้งซื้อแล้วรอของ — แต่ละใบมีหน่วย + บรรทัดรอง (หมดอายุแล้ว N lot / รอนานสุด N วัน) · ระหว่างโหลด (`loaded=false`) แสดง `–` ไม่ใช่ 0 · รายการต่ำกว่า SS เต็มเปิดจาก "ดูทั้งหมด" หัวการ์ด "ยาต้องสั่งซื้อ 5 อันดับแรก" (ทุก role) · E2E 11 เข้า ReorderApp ทางนี้
- **`fetchDashboardAlerts()`** (db.js) — return `{ expiring, lowStock, pendingReceive, drugCount }` — ดึง inventory + receive_logs (paginated) เพื่อคำนวณ `waitDays` ของบิลรอตรวจรับ — ใช้ในคิวงาน (`buildWorkQueue`) + คอลัมน์ภาพรวม (`OverviewPanel` ใน [DashboardPanels.jsx](../../src/DashboardPanels.jsx)). **`drugCount` (การ์ด "รายการยาในคลัง") ต้องใช้กฎเดียวกับ `fetchStockSummary`** (โมดอลที่การ์ดเปิด: qty>0, ไม่ตัดออก, key = รหัส หรือชื่อถ้ารหัส `-`) — เดิมนับรหัสที่คงเหลือ 0 ด้วย การ์ด 430 โมดอล 369 (Rule #6, แก้ 10/10/2569). **คิวงาน (`src/lib/workQueue.js`) ถือ rows ชุดที่นับไว้ในแต่ละรายการ** → โมดอลรายการของคิวแสดง array เดียวกับตัวเลขเสมอ ห้ามให้โมดอล query ใหม่เอง
- **ช่องค้นหาเดียว + บัตรยา** (Phase 2a แผน Dashboard): `CommandPalette.jsx` (Ctrl+K / ช่องบน top bar / `DrugSearchLauncher` บนหน้าหลักเปิดผ่าน `openDrugSearch()` ใน `lib/drugSearchEvent.js`) ผลกลุ่ม "ยา" ก่อน "เมนู" — รายการยา (`fetchDrugSearchIndex`) **โหลดใหม่ทุกครั้งที่เปิด** เพราะ palette อยู่ใน AppShell ไม่ remount ตอนนำเข้า Excel. เลือกยา → `DrugProfileModal.jsx` (state `drugCode` ใน AppRoot) ← `fetchDrugProfile(code)` → `buildDrugProfile`. ปุ่ม "เปิดการ์ดคลัง lot" (staff) ส่ง `initialDrug` ให้ `StockCardApp` แล้วล้างผ่าน `onInitialDrugUsed` (ไม่ล้าง = เข้าเมนู Stockcard ครั้งหน้าเด้งยาเดิม). **ยอดบนบัตรต้องตรงโมดอลรายการยาในคลัง + Dashboard** — ใช้ฟังก์ชันใน drugProfile.js ร่วมกัน ห้ามเขียนสูตรแยก (verify 11/10/2569: 369/369, 393/393). เรท/ช่วงเดือน/`fmtCoverage` ใช้ helper ใน `reorder.js` ตัวเดียวกับ ReorderApp (ย้ายออกจาก component 11/10/2569) · ประวัติรับ/เบิกทุกหน่วยงานทุก role (15/11/2569) — หัวบอก "เบิกบ่อยสุด" (`dispenseHistory().topDept`) · ลิงก์ "ดูทั้งหมด" → `onOpenHistory` (AppRoot `openHistoryFor`) ส่ง `initialDrug` = ชื่อยาใน log (`logDrugName` — 2 หน้าประวัติเลือกยาด้วย `drug_name`) ให้ DispenseLogApp/ReceiveLogApp ตั้งค่าเริ่มต้นแล้วล้างผ่าน `onInitialDrugUsed` · อยู่หน้านั้นอยู่แล้ว = ปิดบัตร + remount ด้วย subKey · ปุ่มคัดลอกข้อความไลน์ = `drugCardLineText` (usageReport.js) · นิยาม CONTEXT §บัตรยา · สถานะ handoff §11.6–11.7 · **ค้นเลข PO (23/11/2569)**: `searchPOs` (drugProfile.js) รวมเป็น 1 รายการต่อ PO (ลำดับ+ปี — PO เดียวกันเขียนหลายแบบ 32.05/032.05 รวมกัน) จำนวนบิล · มูลค่า/รายการเฉพาะแถวของ PO นั้น · ป้าย "ตรวจรับ x/y" จาก `receive_status === 'รอตรวจรับ'` (ไม่ใช่ ap_stage) · รับคำพิมพ์ไม่จบ ("032." · "PO 32") · `searchBills` เหลือเฉพาะเลขบิล + PO รูปแบบแปลก · กด PO → หน้าประวัติรับยาค้นด้วย `po` (แบบที่มีรายการมากสุด) — ⚠️ หน้านั้นยัง ilike ข้อความตรงตัว: PO เขียนแบบอื่นหลุด / 32.05 ติด 132.05 (ข้อ 3 แผนค้นหา PO ยังไม่ทำ) · ยอด PO ที่สั่ง/ส่งครบไหม ยังไม่มี (อยู่ระบบจัดซื้อ — ข้อ 4)
- **`fetchDashboardCharts(months = 6)`** (db.js) — return `{ dispense: [{ ym, label, count, value }], receive: [...], maxValueMonth, maxReceiveValueMonth, trend: { dispensePct, receivePct, dispenseLabels: {cur,prev}, receiveLabels: {cur,prev} } }` — เบิก/รับ รายเดือน ย้อนหลัง `months` เดือน แต่ละเดือนมีทั้ง `count` (จำนวนครั้ง) และ `value` (**มูลค่าบาท** — เบิก = `Σ qty_out×ราคา/หน่วย` ตรงกับ `getPrice` ใน DispenseLogApp; รับ = `Σ total_price_vat` ตรงกับ `totalValue` ใน ReceiveLogApp). **มูลค่าข้ามหน่วยได้** (บาทคือบาท) จึงรวมข้ามแถวได้ — ต่างจากการรวม `qty` ดิบที่หน่วยปน. `trend`/กราฟ/เลขเด่น ใช้ **value** เป็นหลัก. **ไม่ dedup** (ภาพรวม trend — ตัวเลข authoritative ดูในโมดอลสรุปของแต่ละหน้า). **trend % เทียบ 2 เดือนที่จบแล้ว** — `pctInfo` ตัดเดือนปัจจุบัน (`ym === curYm`) ออกก่อนหาคู่เทียบ ไม่งั้นเทียบเดือนครึ่งใบ→เพี้ยน (↓98/99%); `*Labels` = ชื่อเดือนคู่ที่เทียบให้ caption แสดง "มิ.ย. เทียบ พ.ค." (concept เดียวกับ "เรท" CONTEXT.md — ตัดเดือนล่าสุดที่ยังไม่ครบ; AnalyticsApp `momTrend` ใช้กฎเดียวกัน). ใช้ใน `MonthlyFlowChart` ([DashboardPanels.jsx](../../src/DashboardPanels.jsx) — **กราฟเดียว: แท่ง = รับเข้า · เส้น = เบิกจ่าย** แกน y บาทเดียวกัน + คำสรุปเดือนมูลค่าสูงสุด + ลิงก์ไปประวัติเบิก/รับ; Top 5 ยาต้องสั่งซื้อย้ายไปอยู่ `OverviewPanel` จาก `alerts.lowStock` — **พับไว้เป็นค่าเริ่มต้น** (คลิกหัวการ์ดกาง จำไว้ใน localStorage `dashboard_top5_open`) ให้กราฟอยู่ในจอ; สีกราฟเป็น prop JS จึงตาม class `dark` ของ `<html>` ด้วย `MutationObserver` — แก้สีต้องผ่าน validator ของ skill dataviz; โหลดล้ม = `{ error: true }` แสดง "โหลดข้อมูลกราฟไม่สำเร็จ" ห้ามกลืน error ให้ค้าง "กำลังโหลด…" + ฿0) — **แสดงทุก role** (กระดิ่งแจ้งเตือนก็แสดงทุก role แล้ว — staff/admin เห็น global, requester เห็นเฉพาะแผนกตัวเอง ดู [NotificationBell.jsx](../../src/NotificationBell.jsx) + ADR-0010)
