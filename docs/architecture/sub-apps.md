- `StockCardApp.jsx` — **การ์ดคลัง lot (Stock Card)** — เลือกยา 1 รหัส → ประวัติ movement ทุก lot ทุกเดือน (union รับ+เบิก) + **running balance ต่อ lot** คำนวณสด. port สูตรจาก Excel sheet "Stock Card (Lot)" (คลัง verify แล้ว 23/24 ยา). logic อยู่ใน pure module [stockCard.js](src/lib/stockCard.js) — `opening` = 0 ถ้า lot มีประวัติรับ, ไม่มี = `qty_before` แถวแรก; **ไม่หัก balance เฉพาะ `บันทึกเท่านั้น`+`แก้ไขระบบ`** (ที่เหลือหักปกติ รวม `คืนยา`/`ยืมยา`); **balance ติดลบ = data gap ต้นทาง ไม่ใช่บั๊ก**. **drift detection** (Excel ทำไม่ได้): เทียบ balance คำนวณ vs `qty_before` ที่บันทึก — ต่างกัน = มี movement ที่ไม่ถูกบันทึก → badge เตือน ไม่แก้ยอดให้. ⚠️ **ห้าม import `csvfile/Stockcard.csv`** — เป็น export ที่ formula cache ค้าง (ใช้เทียบผลได้ แต่ไม่ใช่แหล่งข้อมูล) ดู CONTEXT.md §การ์ดคลัง lot

- `StockCountApp.jsx` — ตรวจนับคงคลัง (staff/admin) — เลือกรหัสยา → ได้ lot ที่ qty>0 (lot ที่ระบบว่า 0 ซ่อน default กด "แสดงเพื่อนับ" ได้ — phantom stock) แต่ **ติ๊กเลือก lot ที่จะนับ** (`_selected` default true; save/print เฉพาะที่ติ๊ก; ปุ่ม X = `removeDrug` เอายาออกทั้งตัว ≠ checkbox ข้าม lot รายตัว) → นับ **4 มิติ** (จำนวน/ที่เก็บ/exp/**lot**) เทียบ `inventory.qty` สด. **ต้องตรวจครบทุกมิติที่ระบบมีค่าก่อน save** (24/09/2569 — `missingDims()` ใน countMatch.js ใช้ร่วม 3 จุด: `handleSave` เฉพาะจุด / `saveDraft` ประจำปี / `saveEdit` ในประวัติ; มิติที่ระบบเป็น `-` ไม่บังคับ — lot เวชภัณฑ์ 39 lot + ไม่มี exp 37 lot จะบันทึกไม่ได้ตลอดกาลถ้าบังคับ; หน้าเฉพาะจุดเพิ่มช่อง lot + `createStockCount` บันทึก `counted_lot` แล้ว — เดิมไม่มีทั้งคู่); มิติว่าง = "ไม่ได้ตรวจ" ไม่ใช่ "ตรง" — logic เทียบทั้งหมดอยู่ใน pure module **`src/lib/countMatch.js`** (`dimStatus`/`computeCountMatch`/`diffLabel`; ที่เก็บ/exp เทียบแบบ **set equality** split comma ไม่สนลำดับ — แต่ **`counted_lot` เทียบตรงตัว** trim + ไม่สนพิมพ์ใหญ่เล็ก **ห้ามใช้ `setEq`** เพราะ lot เป็นรหัสเดียว comma ในชื่อไม่ใช่ตัวคั่น; `counted_lot` ว่าง = ไม่ได้ตรวจ คนละคอลัมน์กับ `lot` ที่เป็น snapshot ของระบบ). **ช่อง "ที่เก็บจริง" = `LocationInput`** (พิมพ์เองได้ + เลือก suggestion ซ้ำ = append ต่อท้ายคั่น comma). วันที่รอบ (`counted_at`) เลือกได้ตอนนับ + แก้ได้ในประวัติ (ปุ่มดินสอบนหัวรอบ → `updateStockCountSession`). **draft กันงานหาย**: เก็บ localStorage ต่อ user (`stockcount_draft_<username>`) + banner กู้คืน/ทิ้ง (ไม่ auto-restore). append-only เก็บ `stock_count_session`+`stock_count_item` (freeze snapshot, ไม่แก้ qty) + พิมพ์ใบเดินนับ (มี LINE WebView fallback แล้ว). ประวัติ: badge "ไม่ตรง N รายการ"/"ตรงทั้งหมด" (เฉพาะตรวจครบทุกมิติ)/"ตรงตามที่ตรวจ" บนหัวรอบ (จาก `allItems` โหลดครบทุกรอบ), ส่วนต่างแสดง "ขาด N/เกิน N", ค้นยา → **timeline ทุกครั้งที่เคยนับ** + chip "นับล่าสุด" ในหน้านับ (ดู [ADR-0008](docs/adr/0008-stock-count-append-only-snapshot.md))
  - **รอบตรวจนับประจำปี (`kind='annual'`)** — แยกจาก spot check ด้วย `stock_count_session.kind` (`'spot'`|`'annual'`): ระบบ gen ทุก lot ที่มีของ (~632 บรรทัด) แล้วไล่นับ**ตามชั้นวางบนลงล่าง** ไม่ใช่เลือกยาเอง. **draft อยู่บน DB ไม่ใช่ localStorage** (ต่างจาก spot check) เพราะงานกินเวลาหลายวัน ข้ามเครื่อง/ข้ามวัน — `status='draft'` ระหว่างนับ → `'done'` ตอนปิดรอบ; `fetchOpenAnnualCount()` หา draft ค้างตอนเปิดหน้า. บันทึกอัตโนมัติรายบรรทัดด้วย `updateAnnualCountLine()` ซึ่ง **ไม่เขียน audit log โดยเจตนา** (632 แถวจะท่วมกระดิ่ง) — เขียนเฉพาะระดับรอบ: `createAnnualCount`/`closeAnnualCount`/`addLotToAnnualCount`/`addUnknownItemToAnnualCount`. เจอของที่ไม่มีในระบบระหว่างนับ → `addUnknownItemToAnnualCount` (action `add_unknown_count_item`). migration: `stock_count_followup_migration.sql`
  - **ประวัติแสดงเฉพาะ "บรรทัดที่นับแล้ว"** (มี `counted_qty`) — บรรทัดที่ระบบ gen รอไว้คือ*งานที่เหลือ* ไม่ใช่ผลการตรวจ. สลับดู "ทั้งหมด" ได้ต่อรอบ และ **Excel ออกตามที่ตารางแสดงอยู่** (Critical Rule #6) แต่ **ใบรับรองล็อกที่ "นับแล้ว" เสมอ ไม่ตามตัวสลับ**. กรอง 3 จุด: ตาราง+timeline ([StockCountApp.jsx](src/StockCountApp.jsx)) + `lastCounted` ใน `fetchCountPriorityData` ([db.js](src/lib/db.js) — ไม่กรองแล้วยา 333 รหัสที่ไม่เคยนับจะกลายเป็น "เพิ่งนับวันนี้" แล้วหล่นจากอันดับควรนับก่อน). ดู [ADR-0026](docs/adr/0026-count-certificate-from-counted-lines.md)
  - **ใบรับรองผลตรวจนับ** — [stockCountCertificate.js](src/lib/stockCountCertificate.js) `printCountCertificate(session, allItems, { printedBy })` ส่ง **allItems ทั้งรอบ ไม่ต้องกรองมาก่อน** (ฟังก์ชันกรองเอง + ต้องใช้ตัวส่วนไปแสดง "ยังไม่ได้นับ N"). เลขที่ `SC-<session id>`, ลายเซ็น 2 ช่อง (เจ้าหน้าที่คลัง + หัวหน้าคลัง), หัวกระดาษเปลี่ยนตาม `status` (draft = "บันทึกผล…" / done = "ใบรับรอง…"), คอลัมน์ "มิติที่ตรวจ N/4" + `item_note`. ใช้ `openPrintView` (Rule #4) — **`printCountSheet` เดิมยัง copy Blob+fallback เอง ยังไม่ย้ายมาใช้ helper กลาง**
