### YouTube (ดึงคำบรรยายด้วยวิธีใน memory `reference_mobile_app_videos` — Playwright MCP ดัก `/api/timedtext` ของตัวเล่น)

1. **NN/g — [Navigation Menus: 5 Tips to Make Them Visible](https://www.youtube.com/watch?v=Vp77JWjjaiQ)** (34k)
   - ขนาดเมนูให้สัมพันธ์กับจอ · วางในที่คนคุ้น (ซ้าย/บน) · ต้องดูกดได้ (ไม่กลืนกับพื้น) · เว้นที่รอบเมนู · **contrast ข้อความต้องอ่านได้**
   - ผลรวมสะสม — ผิดหลายข้อพร้อมกัน คนจะไม่เห็นเมนูเลย
2. **DesignCourse — [11 UX Tips for Successful Navigations](https://www.youtube.com/watch?v=D29KL52Srtw)** (42k)
   - แยกโลโก้ออกจากเมนู · **มี active state ชัด** · มีปุ่มหน้าหลักแยก (ไม่พึ่งโลโก้) · **แยกเมนูหลักกับเมนูรองให้ต่างกัน (ลำดับชั้นตัวอักษร)** · hover state · contrast ≥ 4.5:1 · อย่าใช้ hamburger บนคอม · ใช้ตำแหน่งที่คนคุ้น · โฟกัสคีย์บอร์ดต้องเห็น · ปุ่มใหญ่พอกดบนมือถือ
3. **Distribution & Warehousing Tips — [Warehouse Bin Location Labeling: The Complete Guide](https://www.youtube.com/watch?v=mipXk5E1ujg)** (195k)
   - รหัสตำแหน่ง 5 ส่วน: **พื้นที่ (area) → แถว (row) → ช่องเสา (bay) → ชั้น (level) → ช่อง (bin)** · ชั้น 1 = ชั้นล่างสุดที่หยิบของ
   - "หยิบใครก็ได้จากถนนมาทำงานแล้วต้องเข้าใจทันที" — ทุกช่องที่เก็บของต้องมีป้ายของตัวเอง แยกจากช่องข้างๆ ได้ชัด
   - คลังเรา: `A-1-3` = โซน(Log A)-ชั้น-ช่อง · พื้นที่อื่นที่ไม่มีรหัสแบบนี้ (คลังน้ำเกลือ, ห้องประชุม) = "พื้นที่อื่น"

## 2. สิ่งที่นำมาใช้

### หน้าแผนผังคลังยา
| หลักการ | ที่มา | ทำอะไร |
|---|---|---|
| ทุกช่องต้องมีป้ายของตัวเอง | Bin Location Labeling · InventiEase | ช่องบนผังแสดงรหัสตำแหน่ง + จำนวนยา (เดิมสี่เหลี่ยมสีไม่มีตัวอักษร) |
| เห็นทั้งคลังในภาพเดียว | InventiEase | ค่าเริ่มต้น = ผังรวมทุกโซน (เดิมทีละโซน) |
| ค้นหาบนผัง → ไฮไลต์ | InventiEase | ช่องค้นหาบนสุด ช่องที่ตรงขึ้นกรอบเหลือง |
| ของที่ไม่ใช่ผังไม่ควรอยู่เหนือผัง | NN/g (เมนู/เนื้อหาหลักไม่ถูกดันลงกลางจอ) | การ์ดตัวเลข 3 ใบ → ป้ายแถวเดียว · ตัดแผง % การใช้พื้นที่ |
| สีต้องมีคำอธิบาย | NN/g contrast · DesignCourse | legend เหนือผัง (มียา / ใกล้หมดอายุ / หมดอายุ / ว่าง / ตรงคำค้น) |

## 3. ที่ยังไม่ได้ทำ (เสนอได้ถ้าต้องการ)
- ผังพื้นตามตำแหน่งจริงของชั้นวางในห้อง (แบบ InventiEase) — ตอนนี้เป็นการ์ดโซนเรียงกริด ไม่ได้วางตามแปลนห้องจริง ต้องมีแปลนห้องคลังก่อน
- เรียงชั้นจากบนลงล่างแบบชั้นวางจริง (คลิป: ชั้น 1 = ล่างสุด) — ตอนนี้เรียงชั้น 1 ไว้บนสุด ต้องถามหน้างานว่าคลังเรานับชั้นแบบไหน
- เกณฑ์สีเหลืองบนผังใช้ "ใกล้หมดอายุ 16 เดือน" ตามป้ายเดิมของหน้านี้ → ช่องส่วนใหญ่เป็นเหลือง ถ้าอยากให้เด่นเฉพาะของใกล้จริงๆ ปรับเป็น ≤ 90 วันได้
