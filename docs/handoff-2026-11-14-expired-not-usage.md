1. **git pull** (หลัง user สั่ง commit + push จากเครื่องบ้าน)
2. **แก้สูตรชีทวิเคราะห์สั่งซื้อ** (`ยอดคลังยา_69.xlsm`) — โหลด `/excel-com` ก่อน · คอลัมน์เบิกรายเดือน E–P (สูตร SUMPRODUCT ที่มี `เบิกยา[หน่วยงานที่เบิก]<>"เบิกเพื่อแลกเปลี่ยนคืนยา"`) เพิ่มเงื่อนไข `*(เบิกยา[หน่วยงานที่เบิก]<>"เบิกยาหมดอายุจากคลัง")` ทุกแถว
   - ค้นหาสูตรอื่นในไฟล์ที่มีคำว่า `เบิกเพื่อแลกเปลี่ยนคืนยา` ด้วย ทุกจุดที่ตัดแถวไม่ใช่การใช้ต้องตัดตัวนี้เหมือนกัน
   - verify: 6 รหัสข้างบน ยอด ส.ค.–ต.ค. ลดลงเท่าแถวหมดอายุพอดี · รหัสอื่นไม่เปลี่ยน (diff ทีละเซลล์กับสำเนาเดิม) · แล้ว `npm run import:reorder` ถ้าค่า VEN/exclude ไม่เปลี่ยนไม่ต้อง
