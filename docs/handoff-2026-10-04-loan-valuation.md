## 3. ตัดสินใจแล้ว — ไม่ต้องถามซ้ำ
- `คืนยา` ฝั่งรับเข้า (Master) = ผู้ที่ยืมยาเราไปนำมาคืน **ความหมายเดียว**; ของทดแทนจากบริษัทในรอบเปลี่ยน/คืนบริษัทห้ามลง `คืนยา`
- คู่ยืม = รพ.อื่น **และบริษัท** ทั้งสองทิศ · หน่วยงานภายใน รพ. "ยืม" = เบิกใช้ ไม่ใช่ลูกหนี้ยืม
- ราคายารับคืน = ราคาทุนเดิมของยาที่ให้ยืมไป (จากชีท `รพ.ยืมยา`) · ยืมเข้ามีมูลค่า = ราคาซื้อล่าสุด
- มูลค่าคงคลัง (AB) = ของบนชั้นเท่านั้น; ลูกหนี้ยืมแสดงแยก · ลูกหนี้/เจ้าหนี้ = ยอดสะสมระดับสรุป ยกข้ามเดือน (ไม่ผูกแถว lot)
- ทะเบียนยืม-คืน = ชีท `รพ.ยืมยา` ในไฟล์รับยา (นำเข้าแอปเป็น `drug_loan`) — ยอดค้างต้องเท่ากับลูกหนี้/เจ้าหนี้ใน Master ทุกเดือน
- ยา TB 3 ตัว (Isoniazid/Pyrazinamide/Rifampicin ยืม รพ.ปทุมธานี 23/12/68) ไม่ตั้งเจ้าหนี้ยืม (ขาผ่านคลัง ADR-0025)
- ระเบียบข้อ 210 ครอบเฉพาะยืมระหว่างหน่วยงานของรัฐ — ใบยืมกับบริษัทไม่ควรอ้างข้อ 210 (ฟอร์มยังมีช่อง "บริษัทยา" — ยังไม่ได้ถามงานพัสดุ)
- (เดิม) 28 แถวราคา/หน่วย = 0 ตั้งใจ · Module2 ห้ามรัน/ห้ามแก้ชื่อชีท · AF/AH ไม่เปลี่ยนเป็น COUNTIFS

## 4. ข้อสังเกตที่ยังไม่แก้
- Streptokinase A03225003 (ยืมเข้า) ถูกลงเบิกด้วยชนิดรายการ `คืนยา` (แถว 3044) — ผิดนิยามใหม่ แต่ปิดไปแล้ว
- Omeprazole แถว `ยืมยา` 2 แถว ("ใบยืมยาคลังบันทึก" NP26099A/NP26100A) ไม่มีในทะเบียนยืม-คืน — มูลค่า 0 ไม่กระทบ
- คอลัมน์ Y (มูลค่าคงเหลือ) ยังยกเว้น `คืนยา` — ไม่กระทบยอดส่งบัญชี
- ชื่อ รพ. ในทะเบียนไม่สม่ำเสมอ (`โรงพยาบาลสามโคก` vs `รพ.สามโคก`)
