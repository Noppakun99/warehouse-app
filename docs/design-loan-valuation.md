ให้ยืม/คืนออกไป รพ.อื่น ปีงบ 69 ≈ 48,179 บาท (สามโคก 18,604 · คลองหลวง 9,700 · ลาดหลุมแก้ว 7,201 · ปทุมธานี 6,420 · หนองเสือ 3,852 · เปาโล 1,892 · เกษมราษฎร์ 510)
ผล: มูลค่าคงคลัง (AB) ต่ำกว่าจริง · มูลค่าเบิกใช้ (Z) สูงกว่าจริง · ยาที่รับคืนอยู่บนชั้นแต่บัญชี = 0

ระเบียบพัสดุ 2560 ข้อ 210: ยาเป็นพัสดุใช้สิ้นเปลือง ผู้ยืมต้องคืน "ประเภท ชนิด ปริมาณเช่นเดียวกัน" (คืนเป็นของ) → ของที่ให้ยืมไปยังเป็นทรัพย์สินของเรา (ลูกหนี้ยืมพัสดุ) ไม่ใช่การใช้ไป

## 2. หลักการ
```
ยกมา + ซื้อ + รับคืน + ยืมเข้า − เบิกใช้ − ให้ยืมออก − คืนยาที่ยืมมา = คงคลัง
```
- **ยอดซื้อ (AA) ไม่เปลี่ยน** — ตรงทะเบียนส่งบัญชีเหมือนเดิม
- **จำนวน (S/T/U) ไม่เปลี่ยน** — แยกเฉพาะฝั่งมูลค่า, T ยังเป็นยอดออกรวม
- **มูลค่าออกรวม ไม่เปลี่ยน** — แค่แยก 3 ช่อง
- ราคายารับคืน = **ราคาทุนเดิมของ lot ที่ให้ยืมไป** (ไม่รู้ lot → ราคาซื้อล่าสุดของรหัสนั้น) → ครบรอบยืม-คืน มูลค่าสุทธิ = 0

## 3. แก้ใน Excel

### 3.1 ชีท `เบิก ` (table เบิกยา)
- เพิ่มคอลัมน์ **ท้ายตาราง** (AD): `ประเภทการจ่าย` · data validation: `เบิกใช้` / `ให้ยืมออก` / `คืนยาที่ยืมมา` · ว่าง = เบิกใช้
- ย้อนกรอกแถวเก่าที่หน่วยงานเป็น รพ.อื่น (~20 แถว) จากหมายเหตุ → **ทำรายการให้ user ตรวจก่อนเขียน**
- macro Sheet10 ใช้คอลัมน์ ≤ 22 (V) → เพิ่ม AD ไม่ชน (ตรวจ 04/10/2569)
- ⚠️ ห้ามแก้ L (ชนิดรายการ) — สูตร T ของ Master SUMIFS จับคู่ชนิดรายการ

### 3.2 ชีท `Master` — เพิ่มคอลัมน์ท้ายตาราง (ต่อจาก AX; ห้ามแทรกกลาง — macro อ้าง index ตายตัว)
| คอลัมน์ | ชื่อ (เลี่ยงคำที่แอปค้นหัว: รายการยา / ชนิดรายการ / หน่วย / lot / เลขที่บิล / สถานะตรวจรับ) | สูตร |
|---|---|---|
| AY | `ปริมาณให้ยืมออก` | SUMIFS แบบสูตร T + `เบิกยา[ประเภทการจ่าย]="ให้ยืมออก"` |
| AZ | `ปริมาณคืนออก` | SUMIFS แบบสูตร T + `="คืนยาที่ยืมมา"` |
| BA | `มูลค่าให้ยืมออก` | AY × J |
| BB | `มูลค่าคืนออก` | AZ × J |
| BC | `มูลค่ารับคืน+ยืมเข้า` | ถ้า M ∈ {คืนยา, คืนยา(2), ยืมยา}: (S − N) × J (แบบ AF บริจาค — นับเฉพาะของใหม่ในงวด) |

แก้สูตรเดิม:
- **Z (เบิกใช้)** = (T − AY − AZ) × J (เงื่อนไขยกเว้นบริจาค/โครงการคงเดิม; **เอา `คืนยา` ออกจากรายการยกเว้น**)
- **AB** = AC + AA + BC − Z − BA − BB (+Y ถ้าแก้ไขระบบ) — **เอา `คืนยา` ออกจากรายการที่ AB = 0**
- แถว `คืนยา` ที่ราคา/หน่วย = 0 (Favipiravir, Lorazepam 2 lot, Manidipine, Calcium gluconate) → ใส่ราคาทุนเดิมก่อน

### 3.3 แถวสรุปใต้ตาราง Master (สำหรับบัญชี) แยก ยา / มิใช่ยา
| ยกมา | ซื้อ | รับคืน+ยืมเข้า | เบิกใช้ | ให้ยืมออก | คืนออก | คงคลัง | ตรวจสมการ |
- แถวตรวจ: ยกมา + ซื้อ + รับคืน − เบิกใช้ − ให้ยืม − คืนออก = คงคลัง → ✅/❌
- ยอดค้าง: **ลูกหนี้ยืม** = ให้ยืมสะสม − รับคืนสะสม · **เจ้าหนี้ยืม** = ยืมเข้าสะสม − คืนออกสะสม → เทียบ DrugLoanApp (drug_loan) ในแอป

### 3.4 ชีท `วิเคราะห์สั่งซื้อ`
สูตรเบิกรายเดือน E–P เพิ่มเงื่อนไข `เบิกยา[ประเภทการจ่าย]` ≠ ให้ยืมออก/คืนยาที่ยืมมา → อัตราการใช้ไม่ถูกดันจากการยืม (ROP ไม่สูงเกินจริง)
