# 0027. ไฟล์ Excel คลังเป็นตัวจริงของ inventory และ dispense_logs

- **Status:** Accepted
- **Date:** 2026-09-28

## Context

คลังทำงานประจำวันในไฟล์ `ยอดคลังยา_69.xlsm` — ชีท `Master` (คงเหลือราย lot) และชีท `เบิก ` (ประวัติเบิก 1 แถว = 1 เหตุการณ์). แอปรับสองชีทนี้เข้า `inventory` และ `dispense_logs` ผ่านการ export CSV แล้วอัปโหลด ซึ่งลบทั้งตารางแล้วใส่ใหม่ (ณ 2026-09-28 ทุกแถวใน `dispense_logs` เป็น `source='csv'` — 8,110 แถว ตรงกับ Excel ทุกยอด).

ผู้ใช้ต้องการให้แอปอ่าน `.xlsm` ตรงและตามการเปลี่ยนแปลงของไฟล์ได้ทันทีที่เซฟ (เพิ่ม/ลบ/แก้แถว). ระหว่างนั้นแอปเองก็แก้สองตารางนี้ได้ — หน้าประวัติเบิกมีปุ่มแก้แถวเบิก และปุ่มลบแถวเบิกที่บวกยอดคืน `inventory.qty`. เมื่อสองฝั่งไม่ตรงกันต้องมีฝั่งที่ชนะ.

## Decision

เราจะถือ **Excel เป็นตัวจริงเสมอ** สำหรับ `inventory` และ `dispense_logs`. การ sync เทียบไฟล์กับ DB ทั้งตาราง และส่วนต่างทุกแถว — รวมถึงแถวที่ถูกแก้/ลบในแอป — จะถูกพาไปเป็นตามไฟล์. ทุกการ sync ต้องแสดงส่วนต่าง (เพิ่ม/ลบ) ให้คนตรวจและกดยืนยันก่อนเขียน DB — ไม่มี sync อัตโนมัติแบบไม่มีคนดู.

## Consequences

- Positive: มีแหล่งความจริงเดียว ไม่ต้องจำว่าแถวไหนแก้ในแอป; ยอดในแอปเทียบกับ Excel ได้ตรงๆ ทุกเมื่อ.
- Negative / trade-off: การแก้/ลบแถวเบิกในหน้าประวัติเบิกเป็นแค่ชั่วคราว — sync รอบถัดไปจะทับกลับ. ถ้าจะแก้ข้อมูลต้องแก้ใน Excel.
- ขยายไปไฟล์รับยา (2026-09-28): ปุ่มเดียวกันนำเข้า `receive_logs` (DELETE ALL เหมือนกัน) + `drug_loan` (diff ไม่ลบ) — **ข้อยกเว้นของ "Excel เป็นตัวจริง"** คือของที่แอปสร้างใน `receive_logs` (สถานะ AP/รูปตรวจรับ/บิลสแกน) ไฟล์ไม่มี ด่าน `app_only_data` จึงบล็อกแบบข้ามไม่ได้ และ `drug_loan` ไม่ลบแถวที่หายจากไฟล์ (ADR-0025)
- Follow-ups / risks: ปุ่มแก้/ลบในหน้าประวัติเบิกยังอยู่ (ยังไม่ซ่อน/เตือน). ถ้าวันหนึ่งแอปเริ่มบันทึกการเบิกเอง (เช่น จ่ายจากใบเบิกลง `dispense_logs`) ต้องทบทวน ADR นี้ — ไม่งั้น sync จะลบแถวที่แอปสร้าง.

## Alternatives considered

- **แอปเป็นตัวจริงสำหรับแถวที่แก้ในแอป** — ต้องเก็บ flag ต่อแถวและ merge สองทาง สุดท้าย Excel กับแอปไม่ตรงกันถาวร.
- **Sync อัตโนมัติไม่ต้องยืนยัน** (Task Scheduler / macro ตอนเซฟ) — ถ้าไฟล์เซฟค้างครึ่งทางหรือมีคนลบแถวผิด ข้อมูลสต็อกพังเงียบ.
