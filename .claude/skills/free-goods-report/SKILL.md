## ขั้นตอน

### 1. หาแถว + ตรวจความถูกต้อง (อ่านอย่างเดียว)

```bash
python .claude/skills/free-goods-report/scripts/find_rows.py 2026-09-30
```

ดึงแถว `สถานะการซื้อ` = `การบริจาค` / `การสนับสนุน` ที่ `วันที่รับ` ตรงวัน แล้วจับคู่ Master (lot + วันที่รับ) — ขึ้น ⚠ เมื่อ:

| ⚠ | ทำอะไร |
|---|--------|
| รหัสไม่ตรง รับยา vs Master | มักเป็น**รหัสชั่วคราว** (เช่น `94`) ตอนยังไม่มีรหัส HosXP → แก้ฝั่ง**รับยา**ให้ตรง Master (ยืนยันกับผู้ใช้ก่อน) |
| เลขที่หนังสือ = `รอเอกสาร` / ไม่มี lot | **ถามก่อน** — เคสจริง 30/9/2569 ยาตำราหลวง ผู้ใช้สั่ง "รอไปก่อน" ไม่ทำใบ |
| มูลค่ารวม ≥ 1 แสน | ยืนยันจำนวนกับ**ของจริง/หนังสือ** — เคส 30/9/2569 Paracetamol ชีทกรอก 1,500 กล่อง (400,005 บาท) ผู้ใช้ยืนยันว่าถูกตอนแรก แต่**ของจริงคือ 80 กล่อง** (21,333.60) แก้ทีหลังทั้ง 3 ไฟล์ → อย่ารับคำยืนยันจากตัวเลขในชีท ขอให้นับ/ดูหนังสือ |
| หมดอายุ < 180 วัน | แจ้งผู้ใช้ให้รู้ |

ถามผู้ใช้**ทีละข้อ** พร้อมคำแนะนำ — ห้ามเดาตัวเลขที่จะพิมพ์ลงหนังสือราชการ

### 2. ขนาดบรรจุ — ขอรูปกล่องถ้าในชีทไม่มี

ชีทมีแค่หน่วยนับ (`vial`, `1000เม็ด`) ไม่บอกว่ากล่องมีอะไร → ขอรูปกล่องจากผู้ใช้ ตัวอย่าง Metalyse: "1 vial of powder 40 mg + 1 pre-filled syringe 8 ml solvent" → `บรรจุ 1 กล่อง/1 vial พร้อมตัวทำละลาย 8 ml`. เทียบ Batch/EXP บนกล่องกับชีทด้วย

ถ้าผู้ใช้ให้เติมขนาดบรรจุลง**ชื่อยา**ใน Excel ด้วย → ต่อท้ายแบบ convention เดิม `<ชื่อ> ,<ขนาดบรรจุ>` (เช่น `Acetaminophen 250mg/5ml ,60ml ,Para`) แก้ **2 ที่**: `Master!H<แถว>` + `รับยา!D<แถว>`. คอลัมน์ M/R ของชีท `Stock Card (Lot)` เป็นผลสูตร spill — ไม่ต้องแก้. **ห้ามแก้ชื่อเฉพาะแถวเดียวถ้ายานั้นมีหลายแถวใน Master** (ชื่อแตก → lookup ด้วยชื่อพัง)

### 3. แก้ Excel — ผ่าน Excel COM เท่านั้น ห้าม openpyxl เขียน

openpyxl เซฟ `.xlsm` แล้ว**ทิ้ง Data Validation extension** (เตือนตอนโหลด) → ใช้ PowerShell COM: attach Excel ที่เปิดอยู่ (`GetActiveObject`) ถ้าไฟล์เปิดค้างอยู่ใช้ workbook นั้น ไม่งั้น `Workbooks.Open` เอง → **เช็คค่าเดิม + รหัส/lot ของแถวก่อนเขียน** (กันแถวเลื่อน) → `Save()` → ปิดเฉพาะที่เปิดเอง. ช่องรหัสในรับยาเป็น text format (`@`) → เขียนเป็น string. ทศนิยมต้อง cast `[double]21333.6` ก่อนเขียน `Value2` (ไม่ cast = `InvalidCastException` แต่คำสั่งอื่นยังเซฟไปแล้ว → ไฟล์แก้ครึ่งเดียว). ตรวจผลด้วย openpyxl `read_only=True` หลังเซฟ

**แก้จำนวน/มูลค่า** — ช่องที่เป็นค่าพิมพ์ (ไม่ใช่สูตร): `รับยา!J` จำนวนที่รับ · `รับยา!M` ราคารวม (= จำนวน × `L` ราคา/หน่วย; `N` เป็นสูตรใช้เทียบ) · `Master!P` ปริมาณ(เข้า). คอลัมน์มูลค่าใน Master (S/U/AD/AF…) เป็นสูตร คำนวณเอง. แล้วสร้าง .docx ใหม่ทับไฟล์เดิม

### 4. สร้าง .docx

เขียน `jobs.json` (ใน scratchpad) แล้ว:

```bash
python .claude/skills/free-goods-report/scripts/make_doc.py jobs.json
```

```json
{ "date": "2026-09-30",
  "jobs": [ { "out": "สสจ.Paracetamol 500mg_แบบรายงานการรับส่วนแถม_30.9.2026.docx",
              "source": "สำนักงานสาธารณสุขจังหวัดปทุมธานี",
              "items": [ { "text": "Acetaminophen 500 mg (Paracetamol) บรรจุ 1 กล่อง/1000 เม็ด จำนวน 1,500 กล่อง",
                           "lot": "38596608", "exp": "2027-04-23" } ] } ] }
```

- **รวมหลายรายการจากแหล่งเดียวกันในไฟล์เดียว** (`items` หลายตัว → หน้า 1 ต่อด้วย "และ", หน้า 2 เลข ๑. ๒. …)
- **ชื่อไฟล์**: `<ชื่อยาสั้น>[+ยาตัวที่2]_แบบรายงานการรับส่วนแถม_<d>.<m>.<ค.ศ.>.docx`; ถ้ามาจาก สสจ. นำหน้า `สสจ.`
- **`text`** = `<ชื่อยา> บรรจุ 1 <หน่วยใหญ่>/<ปริมาณ> จำนวน <N> <หน่วย>` (ตัวเลข ≥1,000 ใส่ comma)
- **Exp แสดงเป็น พ.ศ.** (ผู้ใช้เลือก 1/10/2569) — สคริปต์แปลงจาก ISO เอง; วันที่เอกสาร = `date` เป็น พ.ศ. อัตโนมัติ

สคริปต์**เขียนทับข้อความใน run เดิม**ของต้นแบบ (ไม่สร้าง run ใหม่) เพื่อคง `w:cs` / font ไทย — ดู memory `thai-docx-generation`. มี assert ทุก run ถ้าต้นแบบถูกแก้ จะหยุดพร้อมบอกว่า run ไหนไม่ตรง → **อย่าปิด assert** ให้เปิดต้นแบบใหม่ดู index (`[r.text for r in p.runs]`) แล้วปรับ `make_doc.py`

**ที่สคริปต์เปลี่ยน (ที่เหลือคงเดิม รวมชื่อผู้ลงนาม):** หน้า 1 วันที่หัว · "จำนวน N รายการ จาก <แหล่ง>" · บรรทัด "คือ …" · วันที่ตรวจรับ 2 จุด / หน้า 2 วันที่ 2 จุด · "จาก <แหล่ง>" · รายการ ๑. พร้อม Lot/Exp

### 5. ตรวจด้วยตา

Word COM `ExportAsFixedFormat(path, 17)` → pymupdf render PNG → Read ดู: **ต้อง 2 หน้า** บรรทัดไม่ทับ ไม่มีคำติดกัน (เคยเจอ `vialLot:` เพราะลบ run ช่องว่าง). ตัวเลขแสดงเป็นเลขไทยเพราะ font ของต้นแบบ — ปกติ

**หลายรายการ (≥3) ล้นหน้า** (เคส 2/10/2569 Volte+ลามาโซน+Myda-B ได้ 3 หน้า): บรรทัด "คือ …" หน้า 1 ยาวขึ้น ~2 บรรทัด และรายการหน้า 2 ยาวขึ้น ~4 บรรทัด
- หน้า 2 ล้น → ลบย่อหน้าว่างหลัง "หน่วยงาน กลุ่มงานเภสัชกรรม…" + ตัด `\n` นำหน้าย่อหน้า "กลุ่มงานเภสัชกรรม…ได้ตรวจรับ" (ลบย่อหน้าว่างก่อนหัวหน้า 2 ไม่ช่วย — หัวเรื่องแค่ขยับขึ้น)
- หน้า 1: ลายเซ็น "นางสาวปภัสรา/หัวหน้าเจ้าหน้าที่" เป็น **text box ยึดกับย่อหน้า** (P12/P18/P20) ไม่ไหลข้ามหน้า → ตกขอบกระดาษเงียบๆ ทั้งที่ Word ยังนับ 2 หน้า. **เช็ค y ของบล็อกสุดท้ายหน้า 1 เทียบใบเดิม** (ใบ 1 รายการ ≈ 721 จาก 792 pt) ถ้าเกิน → ลบย่อหน้าว่าง**เหนือ anchor** (P2 ใต้หัวเรื่อง + P10 ก่อน "เรียน ผู้ว่าราชการ") ให้ทั้งบล็อกเลื่อนขึ้นพร้อมกัน
- เช็คว่าย่อหน้าไม่ใช่ anchor ด้วย `'<w:drawing' in xml` ไม่ใช่ `'drawing' in xml` (namespace declaration ทุกย่อหน้ามีคำว่า drawingml)
- แก้ที่**ไฟล์ผลลัพธ์** ห้ามแก้ต้นแบบ (make_doc.py อ้าง index ย่อหน้าของต้นแบบ)
