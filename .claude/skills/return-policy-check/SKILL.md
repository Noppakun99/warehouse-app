# Skill: return-policy-check

อ่านอย่างเดียว — ไม่เขียน DB/Excel · ตอบในแชทได้เลยไม่ต้องวางแผน

## ขั้นตอน

1. **ฟอร์มนโยบายมีคำตอบใหม่ไหม** — Google Drive MCP `download_file_content` fileId `1MF_VxZvCQpNNPbOPS2MIontNOqHgYG7jVffcP-SPxJI` · `exportMimeType: text/csv` (ห้ามใช้ `read_file_content` — ตัดข้อความยาว)
   - ดูคอลัมน์เวลาประทับ เทียบกับรอบตรวจล่าสุด (17/11/2569: คำตอบล่าสุด 25/11/2025 · 21 บริษัท)
2. **ชีทตรงฟอร์มไหม** — อ่าน (SheetJS อ่านอย่างเดียว) ชีท `เงื่อนไข` + `เงื่อนไข_แจกแจง` ใน `OneDrive\รับจากการซื้อ_ยืม_ตุลา2567-2569.xlsm` เทียบรายบริษัทกับคำตอบฟอร์ม
   - บริษัทในฟอร์มแต่ไม่อยู่ในชีท / ข้อความต่างกัน → แจ้ง user (เติมที่ชีท `เงื่อนไข_แจกแจง` แล้ว `npm run import:receive` — ตาราง `swap_return_policy` ไม่ใช่ที่เติม ดู docs/features/swap-return.md §แหล่งนโยบาย)
   - "ตามเอกสารด้านหลัง" ในฟอร์ม (เช่น ภิญโญ) = ดูแถวแจกแจงแทน ไม่ใช่ข้อมูลหาย
3. **จัด lot คงเหลือ** — `node scripts/return-policy-check.mjs` (`--all` = รายชื่อต้องเช็กเอกสาร/ไม่พบบริษัทด้วย · `--json <path>` = ผลราย lot)
   - ใช้ `fetchCompanyPolicyData` + `buildCompanyPolicyIndex` ตัวเดียวกับหน้านโยบายคืนบริษัท → ตรงแอปทุก lot
   - เน็ตคลังช้า: `fetch failed`/Connect Timeout = ลองซ้ำก่อนสงสัยโค้ด
4. **(ถ้าถามเรื่องบอท) ป้ายในบอทตรงไหม** — ยิง edge function `expiry-alert` ด้วย body `{"dryRun":true}` (ไม่ส่งอีเมล/LINE ไม่ลง audit) แล้วเทียบ `allNoReturn` กับ lot สถานะ `no_return` จากขั้น 3 ต้องตรงกันทุก `code|lot`
5. **สรุปในแชท** — ตารางจำนวนต่อสถานะ + รายชื่อ "บริษัทไม่รับคืน" (รหัส · ชื่อ · lot · exp · จำนวน · บริษัท · เหตุผล) + สิ่งที่ต้องทำ (บริษัทใหม่ที่ยังไม่มีนโยบาย · ข้อความต่างจากฟอร์ม)

## กับดัก

- **"มีบริษัท ไม่มีนโยบาย" ไม่ใช่ "คืนไม่ได้"** — บริษัทที่ไม่อยู่ในชีทเงื่อนไข = ไม่คิดเส้นตาย ไม่เดา (CONTEXT §นโยบายเปลี่ยนยารายบริษัท)
- **lot เดียวกันรับจากหลายบริษัท = ไม่ประเมิน** (ADR-0012) — อย่าเลือกบริษัทให้เอง
- **ห้ามคัดด้วยคำค้นในข้อความนโยบาย** (เช่น grep "ไม่รับ") — รอบ 17/11/2569 ได้พาตาร์แลบ/ไบโอฟาร์มติดเกินจริง ใช้สคริปต์ขั้น 3 เท่านั้น
- แก้กฎใน `buildLotReturnPolicies` ([src/lib/drugProfile.js](../../../src/lib/drugProfile.js)) ต้อง copy ไป `noReturnNote` ใน `supabase/functions/expiry-alert/index.ts` + redeploy (ถาม user ก่อน) แล้วทำขั้น 4
