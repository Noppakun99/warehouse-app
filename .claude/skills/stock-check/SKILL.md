# Skill: stock-check

คำถามแบบ "X เหลือเท่าไหร่" — **ตอบได้เลย ไม่ต้องวางแผน/ถามยืนยัน** (อ่านอย่างเดียว ไม่เขียนอะไร)

## ขั้นตอน

1. รันคำสั่งเดียว — ส่งคำของ user ตรงๆ เป็นคำค้น (ตัดคำว่า คงเหลือ/เหลือเท่าไหร่/ยอด ออก):
   ```bash
   node scripts/stock.mjs <คำค้น...>        # เช่น ors ผู้ใหญ่ · clotri cream · 1650101
   node scripts/stock.mjs <คำค้น> --all     # ดู lot ที่เหลือ 0 ด้วย
   ```
   ทุกคำต้องเจอในชื่อยา (ไม่สนตัวพิมพ์/ช่องว่าง) หรือตรงรหัส HosXP
2. ตอบ user สั้นๆ: **ยอดจ่ายได้** เป็นตัวหลัก + หน่วย (แปลงเป็นหน่วยย่อยถ้าหน่วยเป็น "50ซอง"/"100เม็ด") + ตาราง lot ที่มีของ
3. **ต้องบอกเสมอถ้ามี**: ของรอตรวจรับ (ยังจ่ายไม่ได้ — บอกบริษัท/บิล/วันรับ) · lot หมดอายุแล้ว · ยอดจ่ายได้ = 0
4. ถ้าเจอหลายตัว (เช่น ครีมกับยาอม) ตอบตัวที่ตรงคำถาม แล้วบอกตัวที่ใกล้เคียงสั้นๆ (เช่น ยาสนับสนุนที่ใช้แทนได้)
5. ปิดท้ายด้วยเวลาเซฟไฟล์ล่าสุด (บรรทัด "แก้ล่าสุด") — ค่าที่อ่านคือ cache ตอน Save พิมพ์ใน Excel แล้วยังไม่เซฟจะไม่เห็น; ถ้าสคริปต์เตือนว่าไฟล์เปิดค้าง ให้บอก user

## ค้นไม่เจอ

- ชื่อยาใน Master เป็นอังกฤษติดกัน (`OralRehydration`, `ClotrimazoleCream`) — ลองคำสั้นลง/สะกดอื่น
- ชื่อเรียกย่อที่ไม่อยู่ในชื่อยา (เช่น `ors` → `oralrehydration`) เพิ่มใน `ALIAS` ต้นไฟล์ [scripts/stock.mjs](../../../scripts/stock.mjs) แล้วรันใหม่
- ยังไม่เจอ → ยาอาจไม่มีในคลัง บอก user ตรงๆ ไม่เดา

## ไม่ใช่งานของสกิลนี้

- ยาค้างจ่าย/เบิกแล้วไม่ได้ของ → `drug-shortfall-report`
- ต้องสั่งซื้อไหม/พอจ่ายกี่วัน → ชีทวิเคราะห์สั่งซื้อ (`purchase-request-report`)
- ยอดในแอป (Supabase) — สกิลนี้อ่าน Excel ซึ่งเป็นแหล่งข้อมูลจริง
