# Skill: gpo-exchange-form (ใบขอคืน/แลกเปลี่ยน GPO)

ทำครั้งแรก 12/11/2569 (VX-6911-001 · Levofloxacin 500mg lot A680191 หมดอายุ 11/11/2569) · นิยามเลข VX: [ADR-0024](../../../docs/adr/0024-vendor-exchange-cycle-number.md) + `CONTEXT.md` §เลขที่รอบ

## กฎที่ user สั่ง

- **ใช้ฟอร์ม GPO ต้นฉบับเท่านั้น** ห้ามทำฟอร์มเอง: `Desktop\รวมเบิกยา\PDF\รายการยา\แบบขอคืน-แลกเปลี่ยน_09.pdf` (FM-AJE4-001 แก้ไขครั้งที่ 09) → ทำ PDF → เข้าคิวพิมพ์
- **ช่อง "เลขที่เอกสาร (ของลูกค้า)" เว้นว่าง** (user สั่งเอาออก 12/11/2569) · เลข VX ใช้ในชื่อไฟล์และทะเบียนเท่านั้น
- **วันผลิตต้องมาจากรูปกล่องจริง** (ช่อง Mfd. บนกล่อง GPO เป็น `วว ดด ปป` ค.ศ.) · ไม่มีรูป = เว้นว่าง แล้วขอรูปจาก user ห้ามเดา
- ผู้ลงชื่อขอคืน/แลกเปลี่ยน = หัวหน้ากลุ่มงานเซ็นเอง (คลังไม่พิมพ์ชื่อลงช่องเซ็น)
- **ยังไม่ตัดยอดคลังตอนออกใบ** ตัดเมื่อของออกจากคลังจริงเท่านั้น (ดูข้อ 7)

## ค่าคงที่ของ รพ.

รพ. `ประชาธิปัตย์` · จังหวัด `ปทุมธานี` · **รหัสลูกค้า GPO `110000187`** (จากบิล อภ.) · วง "รพ." และติ๊กช่องให้สคริปต์ทำ

## ขั้นตอน

1. **หาข้อมูล lot** (openpyxl อ่านอย่างเดียว · ไฟล์ตัวจริง `OneDrive\ยอดคลังยา_69.xlsm` — memory `live-stock-workbook-path`)
   - Master: รหัส · ชื่อ · หน่วย (I) · ราคาทุน (J) · lot (K) · exp (L) · คงเหลือ (U)
   - บิลซื้ออ้างอิง: ชีท `รับยา` หา lot เดียวกัน → เลขที่บิล (H) + PO (I) → ใส่ช่อง "ได้แนบสำเนาใบส่งของ / ใบกำกับภาษี เลขที่"
   - จำนวนเขียนแบบกล่อง × ขนาดบรรจุ เช่น `1 x 100 เม็ด` · มูลค่า = จำนวนหน่วยใน Master × ราคาทุน J (2 ตำแหน่ง)
   - exp ในตารางเขียน `วว/ดด/ปปปป` ค.ศ. ตามบนกล่อง · ชื่อยาแบบ `Levofloxacin 500 mg Tablet`
2. **วันผลิต**: อ่านจากรูปกล่อง (Lot/Mfd/Exp ต้องตรง Master ทั้ง 3 ค่า ไม่ตรง = หยุดถาม user)
3. **เลข VX**: ดู `Desktop\ยอดคงคลัง\เปลี่ยนคืนบริษัท\_ทะเบียนเลขรอบVX.csv` → `VX-<ปีพ.ศ.2หลัก><เดือน>-<ลำดับ 3 หลัก>` ลำดับนับต่อในเดือนที่ออก
4. **เหตุผลที่ส่งคืน**: ถาม user ถ้าไม่ได้บอก (ใบแรกใช้ `ยาหมดอายุ อัตราการใช้ลดลง`) · โหมด `exchange` = ☑ ขอแลกเปลี่ยน + กรอก "ขอเปลี่ยนเป็นยา" · `refund` = ☑ ขอคืนลดหนี้
5. **สร้าง PDF** — เขียน spec ลง scratchpad (แบบ [scripts/example_VX-6911-001.json](scripts/example_VX-6911-001.json)) แล้ว:
   ```bash
   python .claude/skills/gpo-exchange-form/scripts/gpo_vx_form.py <spec.json> "<out.pdf>" --png <scratchpad>/preview.png
   ```
   **Read preview ทุกครั้ง** ตรวจว่าทุกข้อความอยู่ในช่องและไม่ล้น · ฟอร์มมี 5 แถว เกินให้แยกใบ (เลข VX ใหม่)
   - ไฟล์ออก: `Desktop\ยอดคงคลัง\เปลี่ยนคืนบริษัท\VX-<เลข> GPO <ยา><ความแรง>_<ว.ด.ปป>.pdf` (เช่น `VX-6911-001 GPO Levofloxacin500_12.11.69.pdf`)
   - รูปกล่องเก็บโฟลเดอร์เดียวกัน: `VX-<เลข> รูปกล่อง <ยา> <lot> Mfd-Exp.jpg` (ย้ายออกจากโฟลเดอร์พัก)
6. **คิวพิมพ์ + ทะเบียน**
   - append `<ว/ด/ปปปป HH:MM>,<path เต็มของ PDF>,,` ลง `Desktop\รวมเบิกยา\PDF\_สถานะพิมพ์.csv` (CRLF) → `python scripts/print-queue.py`
   - เพิ่มแถว `_ทะเบียนเลขรอบVX.csv` (เลขที่รอบ · วันที่ออก · บริษัท `องค์การเภสัชกรรม` · รหัส · รายการ · Lot · Exp · จำนวน · หน่วย · บิลซื้ออ้างอิง (PO) · หนังสืออ้างอิง `แบบ GPO FM-AJE4-001 (ขอแลกเปลี่ยน)` · ไฟล์ใบ · หมายเหตุ) — ช่องวันที่ส่งคืน/ผู้แทนรับของ/วันที่รับกลับ/ผลรับกลับ เว้นไว้กรอกตอนของออก/กลับ
   - `_บันทึกเพิ่ม.csv` + `python scripts/daily-log.py`
7. **ตอนของออกจริง / ของกลับ** (ไม่ใช่ตอนออกใบ): ขาออก = แถวชีทเบิก ชนิดรายการ `แลกเปลี่ยนยา` เลข VX ในหมายเหตุ (โหลด `/dispense-entry` + `/excel-com`) · ขาเข้า = ชีท `รับยา` สถานะการซื้อ `แลกเปลี่ยนยา` ช่องเลขที่บิล = เลข VX (ADR-0024) · กรอกช่องที่เว้นไว้ในทะเบียน VX

## แก้ใบที่ออกไปแล้ว (ยังไม่พิมพ์)

แก้ spec → รันสคริปต์ใหม่ → Read preview → **เขียนทับ 2 ที่**: ไฟล์ต้นฉบับใน `เปลี่ยนคืนบริษัท\` และสำเนาใน `PDF\รอพิมพ์\<ว.ด.ปป>\` (แถว `_สถานะพิมพ์.csv` เดิมชี้ path เดียวกัน ไม่ต้องเพิ่มแถว) · สำรองใบเดิมไว้ scratchpad ก่อน · แก้หมายเหตุทะเบียน VX ให้ตรง · ใบพิมพ์ไปแล้ว = ถาม user ก่อนออกใหม่

## กับดัก

- หน้าฟอร์มต้นฉบับมี **rotation 270** — เขียนลงหน้าเดิมตรงๆ ตำแหน่งหมุนผิด สคริปต์จึง render เป็นภาพพื้น 200 dpi แล้ววางข้อความบนหน้าใหม่
- ฟอนต์ THSarabunNew อยู่ `%LOCALAPPDATA%\Microsoft\Windows\Fonts` (ติดตั้งรายผู้ใช้ ไม่ใช่ `C:\Windows\Fonts`)
- พิกัดในสคริปต์ = px ของ preview ที่ 110 dpi — ทดสอบครบทุกช่องแล้ว 12/11/2569 · ถ้า GPO ออกฟอร์มแก้ไขครั้งใหม่ (ไม่ใช่ 09) พิกัดต้องวัดใหม่
- แก้ CSV ทะเบียนด้วย Python: อ่านด้วย `newline=''` เสมอ ไม่งั้น CRLF กลายเป็น LF ทั้งไฟล์ (12/11/2569 เกิดกับ `_ทะเบียนเลขรอบVX.csv` + `_บันทึกเพิ่ม.csv` แก้คืนแล้ว)
