# Skill: work-closeout — ด่านปิดงานกันตกหล่น

สร้าง 24/11/2569 (user สั่ง) หลังพบ 3 จุดตกหล่นในวันเดียว:
1. **พญายอครีม 5g** — user สั่งใส่รายงานแจ้งซื้อ 13/11 · จดไว้แค่ `_นัดเตือน.csv` 19/11 · รอบ 20/11 สคริปต์ไม่หยิบ (สั่งเมื่อขอ) และไม่มีใครอ่านนัดเตือน → หลุด
2. **Tetracaine PO 138.05** — หัวหน้าบอกจะเปลี่ยน 15ml → 1ml · จดแค่ `_บันทึกเพิ่ม.csv` ไม่ลง `_ทะเบียนตามยา.csv` → ร่างไลน์ตามยาไม่มีโน้ตหัวหน้า
3. **Levetiracetam inj/tab + 10 รหัส** — รับเข้า Master แล้วไม่เพิ่มชีทวิเคราะห์สั่งซื้อ → สคริปต์แจ้งซื้อมองไม่เห็น 2 สัปดาห์

## หลักข้อเดียว

> **เรื่องที่ต้องเกิดขึ้นอีกในรอบหน้า ต้องอยู่ในทะเบียนที่สคริปต์อ่านเอง ไม่ใช่ข้อความที่หวังว่าจะมีคนอ่าน**
> `_นัดเตือน.csv` = เตือนให้ user รู้เท่านั้น · `_บันทึกเพิ่ม.csv` = ไดอารี่ส่งหัวหน้า · ทั้งสองไม่มีสคริปต์งานไหนอ่าน
> จดเรื่องเดียวลงหลายที่ได้ แต่ **ต้องมี 1 ที่ที่สคริปต์ของงานนั้นอ่าน** (ตารางล่าง) ไม่มีทะเบียนแบบนั้น = แจ้ง user ว่าเสี่ยงหลุด แล้วเสนอเพิ่มทะเบียน/ด่านในสคริปต์

| เรื่องที่ต้องไม่หลุด | ทะเบียนที่สคริปต์อ่านเอง | สคริปต์/ด่านที่อ่าน |
|---|---|---|
| ใส่ยาเข้ารายงานแจ้งซื้อรอบหน้า (สั่งเมื่อขอ · ยาใหม่ · แจ้งซื้อด่วนนอกรอบ) | `Desktop\ยอดคงคลัง\รายงานขอซื้อยา\_เพิ่มรายงานแจ้งซื้อ.csv` | `pr.py plan` [4e] — รหัสไม่อยู่ชีทวิเคราะห์ = หยุด |
| คำตอบ/คำสั่งหัวหน้าเรื่องยารายตัว (ทางไลน์ · คุยต่อหน้า · หัวหน้าถามเอง) | `…\รายงานขอซื้อยา\_ทะเบียนตามยา.csv` (ช่องทางต้องมีคำว่า "หัวหน้า" + รหัสหรือเลข PO) | `pr.py line` → บรรทัด "หมายเหตุจากพี่" |
| ยาใหม่/รหัสใหม่ใน Master | ชีท `วิเคราะห์สั่งซื้อ` (Table7) | `check-complete.py` ข้อ "ยาใหม่ใน Master ↔ ชีทวิเคราะห์สั่งซื้อ" |
| ไม่แจ้งซื้อยาตัวนี้ (หัวหน้าสั่ง) | ชีทวิเคราะห์ AI = `📋 สั่งเมื่อขอ` + `pr.py plan --cancel` | `pr.py plan` เตือนถ้า AI ยังไม่ตั้ง |
| ยาต้องแพ็ค · ยืม-คืน · ย้ายที่เก็บ · PDF รอพิมพ์ · บิลส่งจัดซื้อ · ตรวจรับ | ทะเบียนของแต่ละเรื่อง | `check-complete.py` (ข้อตามชื่อ) |

## เช็คลิสต์ปิดงานรายประเภท (ทำก่อนบอก user ว่าเสร็จ)

ขั้นตอนละเอียดอยู่ในสกิลของงานนั้น ที่นี่คือด่านท้ายว่าครบ — ข้อไหนไม่ได้ทำ ต้องบอก user พร้อมเหตุผล ห้ามเงียบ

**ลงใบเบิก (`/dispense-entry`)**
- [ ] ชีท `เบิก ` + AD เลขรับใบเบิก + `_ทะเบียนใบเบิก.csv` · PDF + `_สถานะพิมพ์.csv` + `print-queue.py`
- [ ] หน่วยงานภายนอก → ชีท `<ว.ด.ปป>` ในไฟล์สรุปเบิกของศูนย์
- [ ] จ่ายไม่ครบ/ไม่มีจ่าย → หมายเหตุ "ยาหมด-รอของ / แบ่งจ่าย เหลือ N" · ยาที่ต้องแจ้งซื้อเพิ่ม → `_เพิ่มรายงานแจ้งซื้อ.csv` (ไม่ใช่นัดเตือน) + ถาม user ว่าต้องไลน์แจ้งซื้อด่วนไหม
- [ ] เปลี่ยนบริษัท/packsize → V+Q ตอนจ่าย · ยาหมดอายุ → ทะเบียนยาหมดอายุ
- [ ] `import:dispense` (dry-run → `--commit`) · ใบในแอป → ติ๊กจัด/จ่ายออก (check-complete ข้อ 15)

**ลงบิล (`/bill-entry`)**
- [ ] `รับยา` + Master + `รับเข้า` · **รหัสใหม่ → แถวชีทวิเคราะห์สั่งซื้อ (ข้อ 3b)**
- [ ] ดัชนีบิล · ใบส่งบิลจัดซื้อ สบ. + คิวพิมพ์ (ยกเว้นยาเสพติด) · `po_match.py --commit` ลงยามาส่ง
- [ ] exp < 1 ปี / ข้อความเงื่อนไขคืนบนบิล / หนังสือบริษัท → ข้อสังเกต + `เงื่อนไข_แจกแจง` + แจ้ง user
- [ ] `import:receive` + `import:master` (+ `import:reorder` ถ้าเพิ่มแถวชีทวิเคราะห์)
- [ ] ของมาแล้วมีหน่วยงานรอ → แจ้งกลุ่มจัดซื้อทวงตรวจรับ (memory `head-pending-inspection-report`)

**รายงานแจ้งซื้อ (`/purchase-request-report`)**
- [ ] ก่อน `plan`: อ่าน `_เพิ่มรายงานแจ้งซื้อ.csv` + `_ทะเบียนตามยา.csv` + `_นัดเตือน.csv` เรื่องแจ้งซื้อ — นัดเตือนที่ยังเปิดอยู่เรื่องแจ้งซื้อ = ย้ายเข้า `_เพิ่มรายงานแจ้งซื้อ.csv` ก่อน
- [ ] `plan` [4e] ทุกรายการ = เพิ่มรอบนี้ หรือ ✓ ลงแล้ว (แก้สถานะในทะเบียนเป็น `ลงแล้ว <วันที่>`) · exit 2 = ยังไม่อยู่ชีทวิเคราะห์ ห้ามข้ามเงียบ
- [ ] verify OK → publish → สำเนา 6b → `import:purchase` → ถาม user ส่งหัวหน้าแล้วไหม → memory `purchase-report-round-due`

**ไลน์ตามยา / แจ้งซื้อด่วน / ทวงจัดซื้อ (`/purchase-request-report` ขั้น 7 · `/procurement-followup` · memory `urgent-purchase-line-template`)**
- [ ] ก่อนร่าง: อ่าน `_ทะเบียนตามยา.csv` ว่าตัวไหนตามมาแล้วกี่ครั้ง + คำตอบหัวหน้าล่าสุด
- [ ] user บอกส่งแล้ว → append `_ทะเบียนตามยา.csv` ทุกข้อ (1 แถว/ข้อ/รอบ · ช่องทางมีคำว่า "หัวหน้า" ถ้าถึงหัวหน้า · สถานะ `ส่งแล้ว รอตอบ`)
- [ ] แจ้งซื้อด่วนนอกรอบ → `_เพิ่มรายงานแจ้งซื้อ.csv` (วันที่แจ้ง = วันส่งไลน์) ด้วยเสมอ

**หัวหน้าตอบ/สั่ง (ทุกช่องทาง)**
- [ ] เรื่องยารายตัว/PO → `_ทะเบียนตามยา.csv` (หัวหน้าตอบ · วันที่ตอบ · ต้องทำต่อ) **ทันทีในเทิร์นนั้น**
- [ ] เปลี่ยนวิธีทำงาน/ตัดสินใจ → `_บันทึกเพิ่ม.csv` + memory ที่เกี่ยวข้อง
- [ ] คำสั่งที่กระทบรอบหน้า (ไม่ซื้อ · เปลี่ยนขนาด · ซื้อเพิ่ม) → ทะเบียนที่สคริปต์อ่าน (ตารางบน) ไม่ใช่แค่ memory
- [ ] Risk ระดับ E ขึ้นไป → แจ้งพี่โบว์ทันที (memory `risk-e-up-report-immediately`)

**แก้แอป** — `/scrutinize` ก่อน+หลัง · lint/build/test · `_บันทึกเพิ่ม.csv` หัวข้อ `แก้ไขแอป: …` + สถานะ commit/ขึ้นเว็บ

## ด่านสุดท้ายก่อนสรุปงาน (ทุกครั้ง)

1. `python -B scripts/check-complete.py` — อ่านทุกข้อที่ ✗
2. ไล่ "เรื่องที่ user/หัวหน้าสั่งในบทสนทนานี้" ทีละข้อ → แต่ละข้ออยู่ในทะเบียนไหน (ตารางบน) · ไม่มีที่ลง = บอก user
3. `_บันทึกเพิ่ม.csv` → `python scripts/daily-log.py`
4. สรุปให้ user มีหัวข้อ **"ค้าง/รอ"**: รอหัวหน้าตอบ (จาก `_ทะเบียนตามยา.csv` สถานะ `ส่งแล้ว รอตอบ`) · รอ user ส่งไลน์ · รอ commit/push · ไฟล์ในโฟลเดอร์พัก
