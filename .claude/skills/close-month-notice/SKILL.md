# Skill: close-month-notice

user สั่ง 03/11/2569: **ทำทุกเดือนหลังปิดยอด** ทำต่อจาก `anthropic-skills:upgrade-month-v3` และรายงานส่งบัญชี

## ขั้นตอน

1. ต้องมีชีท `Master_<เดือนที่ปิด>` แล้ว · ไม่ต้องปิด Excel (สคริปต์อ่านอย่างเดียว)
2. รันสถานะ PO ล่าสุด: `python -B scripts/po_match.py` (ไม่ใส่ `--commit`)
3. สร้างข้อความ: `python -B scripts/close-month-notice.py --month ต.ค.69`
   - ใช้ไฟล์ `สุรปยอด ส่งบัญชี*.xlsx` ล่าสุดใน `OneDrive\Documents` · ระบุไฟล์เองด้วย `--register <path>`
   - เซฟที่ `Desktop\ยอดคงคลัง\ยอดคงคลังส่งบัญชี\แจ้งจัดซื้อ_<เดือน>.txt`
4. อ่านหัวข้อ "ข้อสังเกตสำหรับคลัง" ก่อนส่ง (ส่วนนี้ไม่ส่งจัดซื้อ)
   - `⛔` ยอดทะเบียนไม่ตรง Master หรือบิลจับคู่ไม่ได้ = หยุด แก้ก่อน ห้ามบอกว่ายอดตรง
   - บิลตรวจรับแล้วแต่ไม่มีใบ ตร. ที่ใช้งานอยู่ = ถาม user ก่อนจัดเข้ากลุ่ม "ตรวจรับแล้ว"
5. ทวนชุด 1 ทีละจุดกับไฟล์ทะเบียน แล้วส่งข้อความ 2 ชุดให้ user ในกล่อง code block ไม่ใช้ตาราง markdown (ไลน์ไม่แสดงตาราง) · ขึ้นต้นคำตอบด้วย `Written for: เจ้าหน้าที่จัดซื้อ ส่งทางไลน์`
6. ก่อนสรุปงาน ถาม user ว่าส่งแล้วหรือยัง + จด `_บันทึกเพิ่ม.csv`

## กติกาข้อความ

- **อ้างตำแหน่งเป็น "แถว D5" เสมอ ไม่เขียน D5 ลอยๆ** (user สั่ง 03/11/2569 ให้คนทำรับรู้ว่าเป็นตำแหน่งแถวในทะเบียน) · ใช้กับ B/C/D ทุกจุด
- ชื่อที่ถูกมาจาก Master คอลัมน์ Q · ชื่อย่อที่ตัดท้าย เช่น `เบอร์ลิน ฯ` ไม่นับว่าผิด
- ชุด 2 แยกครบ: ส่งบัญชีแล้ว · ตรวจรับแล้วยังไม่ส่ง · ยังไม่ตรวจรับ แบ่งเป็น PO ของมาไม่ครบ กับ ของครบรอชุดตรวจรับ
