# กับดัก COM เพิ่มเติม

- **COM เพิ่มเติม (ขึ้นเดือน ต.ค.69, 03–04/10/2569)**: `.Formula` ผ่าน COM คืนรูปย่อ `[@ชนิดรายการ]` ไม่ใช่ `Master[[#This Row],…]` ที่ SheetJS อ่าน — string replace ต้องใช้รูป COM · PowerShell: ห้ามตั้งชื่อฟังก์ชัน `R`/`H` (ชน alias) และ**ชื่อตัวแปรไม่สนตัวพิมพ์** (`$SNAP`=`$snap`) · regex มี `$` ใส่ single quote · ตรวจ syntax ด้วย `Parser::ParseFile` ก่อนรัน · user เปิดไฟล์ใน Excel อยู่ = ห้ามเขียน (ไฟล์ถูกล็อก) ให้ Save+ปิดก่อน · ตรวจ macro ไม่พังด้วย `oletools` (`olevba`) เทียบโค้ดทีละโมดูลกับไฟล์สำรอง · **ชื่อตัวแปรไม่สนตัวพิมพ์ยังโดนซ้ำ 04/10** (`$T` รายการเป้าหมาย + `foreach ($t in $T)` = ตัวเดียวกัน → ลูปแรกเขียนทับรายการ ลูปที่สองพัง — ด่านตรวจจับได้ ไม่ได้ Save) · **แก้สูตร calculated column ทีละเซลล์ต้องปิด `$xl.AutoCorrect.AutoFillFormulasInLists = $false`** ก่อน (แล้วคืนค่าใน `finally`) ไม่งั้น Excel เติมสูตรทั้งคอลัมน์ทับเซลล์ที่พิมพ์ค่าทับไว้ · log ภาษาไทยให้ `Out-File -Encoding utf8` แล้ว `cat` อ่าน (stdout ของ PowerShell ผ่าน bash เพี้ยนเป็น cp874)
- **COM เพิ่มเติม (05/10/2569 บ่าย)**: `Specified cast is not valid` เกิดกับ `.NumberFormat =` และ `.Calculate()` ด้วย (ไม่ใช่แค่ `.Value2`) → ห่อ retry ทุกคำสั่งที่เขียน · แช่ค่าช่วงที่มี array formula ทีละหลายเซลล์ (`$rng.Value2 = $rng.Value2`) ล้มทุกครั้ง → แช่**ทีละเซลล์** · ลงแถวชีท `เบิก ` เองต้องทำตามแมโคร: เติม C–Q จาก Master (E/J เป็น `@`) → `Calculate` R:V → แช่ค่า R:V (`EnableEvents=$false` แมโครไม่ทำงานให้) · sync `รับเข้า` ให้เทียบเฉพาะแถวที่มีข้อมูลในชีทรับยา (ใต้แถวสุดท้ายมีเศษ 0 ค้างใน `รับเข้า` ไม่ใช่ความต่างจริง) · Table1 ชีท `list` เรียงที่เก็บแบบ Excel (ไม่สนขีด: `E-11` อยู่ก่อน `E-1-1`) ไม่มีสูตร/แมโคร/แอปอ้างถึง
