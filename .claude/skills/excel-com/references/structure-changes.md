# กับดักงานเปลี่ยนโครงไฟล์

- ตัดยอดยาเสพติดรายเดือน (ไฟล์ "sub stock ยาเสพติด ส่งยอดคลัง" ของห้องยา → เบิกให้ห้องยาG) ดูนิยาม/กฎใน [CONTEXT.md §ตัดยอดยาเสพติด](CONTEXT.md)
- **⛔ เปลี่ยนรหัสยา (16/10/2569 — ASA เคี้ยว 54→1690073)**: (1) **ชีท `เบิก ` คอลัมน์ T "รหัส_txt" เป็นค่าแช่** ไม่ใช่สูตร และชีทวิเคราะห์สั่งซื้อนับยอดเบิกรายเดือนจากคอลัมน์นี้ → แก้ E **และ** T ไม่งั้นยอดเบิกหายแบบเงียบ (2) **แถว Master ที่ยกมา ต้องเปลี่ยนรหัสใน snapshot เดือนก่อน (`Master_<เดือน>`) ด้วย** ไม่งั้นสูตร S จับคู่ไม่ได้ → ได้ P แทน N → ของเกินเอง (แก้ snapshot ที่ปิดงวดแล้วต้องขอ user ก่อน) (3) **ก่อนเปลี่ยนสแกนรหัสปลายทางทุกชีทก่อน — มีแถวอยู่แล้ว = ชนกัน หยุดถาม** (09/11/2569: 1690065 คือ myda-B 5g ไม่ใช่ 25g) (4) **ทะเบียน CSV ต้องตาม**: `_ดัชนีบิล.csv` คอลัมน์รหัส + `_ทะเบียนเอกสารตรวจรับ.csv` คอลัมน์ `รหัสยา` (ไม่แก้ = check-complete เตือนว่ายังไม่ออกเอกสารตรวจรับ)
- **⛔ เปลี่ยนชื่อยา (19/10/2569 — SilverSulfadiazine 450gm→500gm)**: ชื่อเป็นค่าแช่ใน `เบิก ` G · Master H · วิเคราะห์ C · list H · `รับเข้า` D + ไฟล์รับยา `รับยา` D · List F · Piviot I (pivot ให้ user Refresh) · **Table3 ห้ามทับชื่อเดิม** — snapshot `Master_<เดือน>` ยังใช้ชื่อเดิมหา packsize/หน่วยย่อย (ทับแล้ว AQ ของ snapshot ที่ปิดงวดเปลี่ยน กระปุก→ขวด) → เพิ่มแถวชื่อใหม่ด้วย `ListRows.Add(<index กลางตาราง>)` · สูตร W/X ของชีท `หน่วยย่อย` อ้าง Table3 ช่วงตายตัว `$A$34:$A$507` แถวที่เพิ่มท้ายตาราง (508–522) จึงหลุด · COM `Find` แบบ values ไม่เจอเซลล์ในแถวที่ซ่อน → ไล่เซลล์ด้วย openpyxl
- **copy ชีทข้ามไฟล์ผ่าน COM ต้อง `AutomationSecurity = 1`** (`3` = force-disable ทำให้ `.Copy/.Move` ข้าม workbook **ไม่ทำอะไรเลยและไม่ error**) + `EnableEvents = $false` กัน Workbook_Open → เปิดไฟล์ `.xlsm` ต้นทาง **ReadOnly และห้าม Save** ในรอบนั้น (Save = VBA เป็น 1252 ตามข้อบน). **ยืนยันผลด้วยชื่อ/จำนวนชีท** ไม่ใช่เซลล์ A1 (หัวตารางทุกเดือนเหมือนกัน — 05/10 ด่านเช็ค A1 ผ่านทั้งที่ copy ไม่เกิด แล้วไปเปลี่ยนชื่อชีท ก.ค.69 ผิดตัว)
- **ย้ายชีท snapshot ไปไฟล์รวมปีงบ**: ชีทมีสูตรอ้างชีทอื่น 4 คอลัมน์ — X (`Table7` Safety Stock) · AP/AQ (`หน่วยย่อย`) · AV (`อ้างอิงPOบัญชี`) (ตัวอักษรของ snapshot ก.ย.69 และก่อนหน้า — snapshot จาก Master ต.ค.69 เป็นต้นไปเป็น X · AQ/AR · AW เพราะย้ายคอลัมน์ 06/10/2569) ย้ายแล้วกลายเป็นลิงก์ข้ามไฟล์. **Paste Values 4 คอลัมน์นี้ก่อน Break Link** — Break Link เองคำนวณ `XLOOKUP(TEXT([1]!Table7[…]))` ใหม่ตอนต้นทางเปิดไม่ได้ → **X เป็น 0 ทั้งชีท** (ชีท ก.ค.69 ในไฟล์ปีงบยังลิงก์สดอยู่ 4,504 เซลล์จนแก้ 05/10). ตั้ง `Calculation` manual **ก่อน**เปิดไฟล์ (เปิด workbook เปล่าก่อน) ไม่งั้นเปิดไฟล์แล้วคำนวณ X เป็น 0 ทันที · paste ด้วย `PasteSpecial(-4163)` ไม่ใช่ `Value2 = Value2` (ข้อความตัวเลขใน AV `'562'` กลายเป็นตัวเลข)
