# Skill: excel-com

เขียนกลับลงไฟล์ Excel ของคลัง **ผ่าน Excel COM (PowerShell) เท่านั้น** — ย้ายมาจาก root `CLAUDE.md` 19/10/2569 (กับดักด้านล่างยกมาคำต่อคำ)

## ขั้นตอนบังคับ (ทำตามลำดับ — ข้ามขั้นไม่ได้)

1. **ได้รับอนุญาตให้เขียนไฟล์นี้แล้วหรือยัง** — user ไม่ได้สั่งให้แก้ Excel = ห้ามเขียน (10/10/2569 เคยเขียน `.xlsm` เองต้องกู้คืน)
2. **ไฟล์ว่าง**: ไม่มี `EXCEL.EXE` เปิดอยู่ · ไม่มีไฟล์ล็อก `~$<ชื่อไฟล์>` · user เปิดไฟล์อยู่ = ให้ Save+ปิดก่อน
3. **copy ไฟล์ไป scratchpad** แล้วทำบนสำเนาเท่านั้น (ห้ามเปิดไฟล์ใน OneDrive ด้วย COM แม้งานเล็ก) · เก็บสำเนาเดิมอีกชุดไว้ diff
4. **ตั้งค่า COM**: `AutomationSecurity = 3` (ยกเว้น copy ชีทข้ามไฟล์ — ดูกับดัก) · `Calculation = -4135` · `EnableEvents = $false` · `DisplayAlerts = $false` · แก้สูตร calculated column → `AutoCorrect.AutoFillFormulasInLists = $false` (คืนค่าใน `finally`)
5. **เขียน**: หาแถวด้วยเนื้อหา (รหัส+lot+บิล+ชนิดรายการ) · ตัวเลขเป็น `[double]` · ห่อ retry ทุกคำสั่งที่เขียน · แทรกแถว table ด้วย `ListRows.Add(index)` + copy `Formula2R1C1`
6. **คำนวณ**: คืน `Calculation = -4105` + `Calculate()` (**ห้าม `CalculateFull()`**) → ด่านตรวจยอด ไม่ผ่าน = ไม่ Save
7. **Save ลงสำเนา** → **diff ทีละเซลล์** กับสำเนาเดิม (openpyxl) — ต่างได้เฉพาะเซลล์ที่ตั้งใจ + สูตรที่ตามมา · packsize/หน่วยย่อย (Master AQ/AR) ต้องไม่เปลี่ยน · แถว "ยอด ยา นำไปใช้เดือนถัดไป" ✅ · AC ไม่เปลี่ยน
8. **`.xlsm` ตรวจ VBA**: codepage เท่าเดิม + `olevba` เทียบโค้ดทีละโมดูล
9. **`cmp` ไฟล์จริงยังเหมือนสำเนาเดิม** (ไม่มีใครแก้ระหว่างทำ) → วางกลับ → `cmp` อีกครั้ง
10. **นำเข้าแอป** ถ้าเป็นชีทที่แอปใช้ (CLI dry-run → `--commit` — memory `import-app-after-every-entry`)

## กับดักที่เจอ

**ห้ามใช้ SheetJS เขียน** — macro / table (`Master`, `เบิกยา`, `รับยา`) / สูตร structured reference หายหมด. SheetJS ใช้**อ่าน**ได้อย่างเดียว (ค่าที่อ่านคือ cache ของสูตรตอน Save ล่าสุด). ยังไม่มีสคริปต์ใน repo (ครั้งแรกเขียนชั่วคราวตอนตัดยอดยาเสพติด ก.ย.69 — 03/10/2569) — กับดักที่เจอ:
- **ไฟล์ `.ps1` ต้องมี UTF-8 BOM** ไม่งั้น PowerShell 5.1 อ่าน path ภาษาไทยเพี้ยน → "couldn't find file"
- **`$xl.Calculation = -4135` (manual) ระหว่างเขียน** — โหมด auto คำนวณทั้งไฟล์ทุกครั้งที่เขียน 1 ช่อง (ช่องละหลายนาที) และ COM โยน `Specified cast is not valid` ตอน Excel busy. เขียนผ่าน `Range(addr).Value2` แล้ว fallback `.Value` — **ตัวเลขต้องส่งเป็น `[double]`** (`Int32` โยน `Specified cast is not valid` ทุกครั้ง ไม่ใช่เพราะ busy — 05/10/2569). ก่อน Save คืน `-4105` + **`Calculate()` ห้าม `CalculateFull()`** (ดูข้อถัดไป)
- **⛔ Excel เครื่อง PRH0000484 (build 16.0.20430) ไม่มี `REGEXREPLACE`** (`#NAME?`) และ `SORT` เรียงภาษาไทยคนละแบบกับเครื่องที่ Save ไฟล์ปกติ (cache ในไฟล์มาจากเครื่องที่ Excel ใหม่กว่า — น่าจะเครื่องเดียวกับที่คืน VBA เป็น 874). สูตร packsize/หน่วยย่อย (Master **AQ/AR** — เป็น AP/AQ ก่อน 06/10/2569 และในชีท snapshot เดือนก่อนหน้า) หา `ชื่อยา+หน่วย` ในตาราง `หน่วยย่อย` (Table3) ก่อน ไม่เจอถึงใช้ REGEX → **คำนวณใหม่บนเครื่องนี้ แถวที่ไม่มีใน Table3 ได้ packsize 1 แบบเงียบ** (`100แคปซูล` แทน `แคปซูล`) แล้วลามไปเบิกหน่วยย่อย/วิเคราะห์สั่งซื้อ/Safety Stock. `CalculateFull` ทำให้เกิดแน่ · `Calculate` ก็เกิดถ้าแก้ชีท `รับเข้า`/`หน่วยย่อย` (precedent ของ AQ ทั้งคอลัมน์). 05/10/2569 เพิ่ม 7 คู่ที่ขาดลง Table3 (A515:D521) แล้ว → **ยาใหม่ที่หน่วยมีตัวเลขนำหน้า ต้องเพิ่มลง Table3 ด้วย** ไม่งั้นพังอีก. ชีท `บริษัทไม่มีเงื่อนไข` (ไฟล์รับยา) = `SORT(UNIQUE())` + หมายเหตุพิมพ์มือคอลัมน์ C/D ตามบรรทัด → คำนวณบนเครื่องนี้ลำดับสลับ หมายเหตุเคลื่อนชั่วคราว (กลับเองเมื่อคำนวณบนเครื่องภาษาไทย). ⇒ **diff ทีละเซลล์หลังแก้ทุกครั้ง: packsize/หน่วยย่อย (AQ/AR) ต้องไม่เปลี่ยน**
- **หาแถวด้วยเนื้อหา (รหัส+lot+บิล+ชนิดรายการ) ไม่ใช่เลขแถว** — ผู้ใช้แก้ไฟล์ระหว่างคุย เลขแถวขยับ (แถวที่ผู้ใช้สั่งลบ "336" กลายเป็น 335)
- **ช่อง "ปริมาณ (ออก)" ของ Master = `SUMIFS` จากชีทเบิก match รหัส + lot + ราคา/หน่วย + ชนิดรายการ + ช่วงวันที่** → แถวเบิกที่เพิ่มต้องตรงทั้ง 4 ช่อง ไม่งั้นยอดไม่ลด**แบบเงียบ** (ไม่มี error). แก้ lot ใน Master **ก่อน**ลงแถวเบิกด้วย lot ใหม่
- **เพิ่มแถว Master ต้องแทรกกลาง table (`ListRows.Add(index)`)** ไม่ใช่เขียนลงแถวว่างท้าย table — แถวสรุปส่งบัญชีใต้ table ใช้ช่วง `$2:$<แถวก่อนแถวว่าง>` เขียนท้ายแล้วหลุดจากยอดรวม. calculated column ไม่ auto-fill เสมอ → copy `Formula2R1C1` จากแถวข้างเคียง (ดูข้อ Formula2R1C1 ด้านล่าง)
- **verify ทุกครั้ง**: สำรองก่อน → ตรวจยอดหลัง `Calculate` ถ้าไม่ตรงไม่ Save → อ่านซ้ำด้วย SheetJS/openpyxl เทียบกับไฟล์สำรอง**ทีละเซลล์** + เช็คแถว "ยอด ยา นำไปใช้เดือนถัดไป" ต้องขึ้น ✅ ถูกต้อง และ "มูลค่าคงคลัง เดือนก่อน" (AC) ต้องไม่เปลี่ยน. ⚠️ เดิมเขียนว่า "packsize เปลี่ยนเพราะ cache ค้าง ไม่ต้องตกใจ" — **ผิด**: นั่นคือบั๊ก REGEXREPLACE ข้างบน ค่าใหม่ผิด ห้าม Save
- **diff ด้วย openpyxl (โหมดสูตร) เซลล์ dynamic array ขึ้นว่า "ต่าง" ทุกครั้ง** — `ArrayFormula` เทียบกันด้วย object ไม่ใช่ข้อความ → เทียบ `.text` + `.ref` ก่อนตกใจ (14/10/2569 Sheet1 Q22–Q24 รายงานซื้อยา — สูตรเหมือนเดิม ค่า `#REF!` ค้างมาเดิม)
- **copy สูตรจากแถวต้นแบบใช้ `Formula2R1C1` ไม่ใช่ `FormulaR1C1`** — สูตรส่วนใหญ่ในชีทวิเคราะห์สั่งซื้อ/Master เป็น dynamic array (`LET`/`XLOOKUP` ช่วง `&` ช่วง) `FormulaR1C1` เก็บเป็นสูตรแบบเก่า ข้อความเหมือนกันแต่ไม่ใช่ array (05/10/2569 Table7 17 คอลัมน์ — ตรวจด้วย openpyxl ว่าเป็น `ArrayFormula` เหมือนแถวต้นแบบ)
- **เทียบไฟล์ก่อนวางกลับด้วย `cmp` ไม่ใช่ `sha256sum`** — Git Bash ใส่ `\` นำหน้า hash เมื่อ path มี backslash → เทียบสตริงไม่ตรงทั้งที่ไฟล์เดียวกัน
- **หยุดสคริปต์กลางทาง = Excel ค้างแบบไม่มีหน้าต่าง ล็อกไฟล์ไว้** และ Claude **ไม่ได้รับอนุญาตให้ kill process** → ให้ผู้ใช้ End task `EXCEL.EXE` ใน Task Manager > Details
